## A：宽广度、拆量、额价差与量价指标

### 1. 统一符号与数据分组

令A、D、U分别为同一股票池中上涨、下跌、平盘家数。对每只股票i，rᵢ为所选时点相对参考价的涨跌幅，Vᵢ为成交量，Eᵢ为成交额。按口述“把涨的量和跌的量拆开”，可数学化为：

```text
A  = Σ 1(r_i > 0)           D  = Σ 1(r_i < 0)
V+ = Σ V_i × 1(r_i > 0)     V- = Σ V_i × 1(r_i < 0)
E+ = Σ E_i × 1(r_i > 0)     E- = Σ E_i × 1(r_i < 0)
```

原视频未打开完整的分组程序。日内实时版可能以当前红绿盘对截至当时的累计成交量重新分组，不能因此认定它是逐笔主动买卖拆分。涨跌参考价、ST、停牌、新股、缺数和无成交处理，需要另行固定。

### 2. TRIN / ARMS / 阿姆氏：两种写法，一个双比率

[39] 00:48原画面：

```text
TRIN_量 = (A / D) / (V+ / V-)
        = (A × V-) / (D × V+)

TRIN_额 = (A / D) / (E+ / E-)
        = (A × E-) / (D × E+)
```

画面展示的是成交量版的两种等价写法。成交额版另由[49]口述与[54]输出确认。两种统计口径不应拼为同一条时间序列。

![39号视频00:48：TRIN双比率原式](</Users/yangguang/Documents/Codex/workspace/市场交易信号研究/douyin_research/formula_audit/frames/test39_48.png>)

作者[31]01:31曾把阿姆氏简说成“上涨组成交额/下跌组成交额”，省掉了家数比；同集后文数例和[39]完整公式表明不能按这一简说录入计算。

数值含义是：TRIN<1，上涨组的成交份额高于其家数份额；TRIN>1则相反。它是**相对成交活跃度**，并没有直接提供机构身份或真实净买入额。

作者给出的经验读法包括0.9偏中性、低于0.7/0.6/0.5偏向上涨组相对活跃；但[41]明确只在趋势中后段判断短线转折，趋势初段不这样用。[41]还举出下跌起点TRIN约0.62后继续下跌的反例。因此不能简化成“低于0.7就买入”，这些阈值也不是本次回测结论。

### 3. 宽广度、涨额占比、额价差、量价差

对[54]实时版，定义：

```text
p   = A  / (A + D)
q_E = E+ / (E+ + E-)
q_V = V+ / (V+ + V-)

涨家占比（宽广度）= 100p              [%]
涨额占比          = 100q_E            [%]
涨量占比          = 100q_V            [%]
额价差            = 100(q_E - p)      [百分点]
量价差            = 100(q_V - p)      [百分点]
```

[54]00:30画面显示的是13:44:39快照：

|字段|画面值|交叉检查|
|---|---:|---|
|上涨/下跌/平盘|4381 / 1035 / 159|合计5575，与有效样本一致|
|涨家占比|80.89%|4381/(4381+1035)=80.8899557%，证实该版排平盘|
|涨额占比|83.31%|83.31−80.89=+2.42|
|额价差|+2.42|单位为百分点，约242基点|
|涨量占比|80.15%|80.15−80.89=−0.74|
|量价差|−0.74|单位为百分点|
|TRIN_额|0.848|用两类份额反算约0.847993|
|TRIN_量|1.048|反算约1.048310|

![54号视频00:30：实时拆量字段与额价差](</Users/yangguang/Documents/Codex/workspace/市场交易信号研究/douyin_research/formula_audit/frames/54_0030.jpg>)

这里的分母确认来自具体快照；文件列表能看到`symbols_hs_a.txt`，但内容未打开，不能推断所有样本剔除规则。前面历史视频有不同红盘数值，不应假定全部版本完全同口径。

音频[54]说红盘78%、额价差0.5、TRIN约1，画面却是80.89%、+2.42、0.848，并且显示盘中时间。**不能将口述与这个盘中快照强行拼成一个时点。**计算定义可用同屏值核实，口述值则单独保留为作者报告。

该集01:44还短暂展示另一时点15:27:11的曲线：涨家78.8%、涨额79.2%、TRIN_额0.974；这与口述“78%、约1”的量级一致，也支持两个画面属于不同时间。两个占比都只显示一位小数，不能用相减0.4就否定口述约0.5，更不能将不同精度的显示值当成完整底层数据。

这些指标的代数关系是：

```text
TRIN_额 = [p/(1-p)] / [q_E/(1-q_E)]
q_E     = p / [p + TRIN_额 × (1-p)]

TRIN_额 < 1  ⇔  q_E > p  ⇔  额价差 > 0
```

给定宽广度后，TRIN_额、涨额占比、额价差可以互相换算。**不能将它们算作三份独立证据，重复增加信心。**

### 4. MCL：净上涨家数的双EMA差

[41]04:40，参数N1=19、N2=39：

```text
DIF:=ADVANCE-DECLINE;
EMA1:=EMA(DIF,N1);
EMA2:=EMA(DIF,N2);
MCL:EMA1-EMA2;
MAMCL1:EMA1;
MAMCL2:EMA2;
A:0;
```

因此：`MCL_t=EMA_19(A−D)_t−EMA_39(A−D)_t`。通常EMA递推为`EMA_t=αx_t+(1−α)EMA_(t−1)`，`α=2/(n+1)`，19/39对应0.1/0.05。截图没有说明初始化与预热期；数据范围由软件ADVANCE、DECLINE字段决定。

![41号视频04:40：MCL代码及19/39参数](</Users/yangguang/Documents/Codex/workspace/市场交易信号研究/douyin_research/formula_audit/frames/41_0280.jpg>)

这与McClellan振荡器的经典结构一致，亦经[指标发布者说明](https://www.mcoscillator.com/learning_center/kb/mcclellan_oscillator/the_mcclellan_oscillator_summation_index/)交叉核验。代码没有按总家数归一化，也没有累加为求和指数。MAMCL1/2是直接输出两条EMA，不是再次取均线。

总览图写“MCI”，原代码实际写“MCL”。[42]01:00图中的“MCL37%”也不是原始MCL自然输出的百分数；图标题明确是**各指标历史分位**。历史样本长度、排名并列处理、是否滚动等仍未公开。

### 5. 站上均线的比例、综合评分和历史分位

[31]01:30的“全市场宽广度雷达KDRADAR”图例包括综合评分0–100、站上MA20家数%、站上MA60家数%、站上年线家数%；[42]显示P20/P60/P250标签。

对这些标签，可恢复其指标含义的数学表达：

```text
MA_n(C_i,t) = 最近n个周期收盘价的简单平均
P_n(t)      = 100 × Σ_i 1[C_i,t > MA_n(C_i,t)] / N_t
n           = 20、60、250
```

未公开之处：股票池、复权、上市不足n期是否剔除、停牌与缺值、当日盘中价是否替代收盘价，以及综合评分的权重/变换。不能据图例编出一个“综合评分=几项等权平均”。

[42]01:00截图的82.5%、37%、14.4%、12.3%、13.7%、9.4%是各字段的**历史分位**，不能当成当日红盘率、原始MCL或站上均线比例。这解释了此前只读字幕时出现的“红盘74%与82.5%冲突”：前者是[41]口述的当日水平，后者是历史分位，不构成可直接比较的两个红盘率水平。

## B：期权、PCR轨道与衍生品观察点

### 1. PCR必须先明确分子分母的“统计量”

音频[07][08]用“买call和买put的人一个比值”来解释，并没有把成交量、持仓量或成交额说清楚。标准PCR按Put/Call定义，至少区分：

```text
PCR_volume = Σ Put成交张数 / Σ Call成交张数
PCR_OI     = Σ Put未平仓张数 / Σ Call未平仓张数
PCR_amount = Σ Put成交金额 / Σ Call成交金额
```

上述是**标准口径清单，非三项都已被作者使用的证据**。Cboe对其成交量版的定义及案例表明，提前行权相关、没有明显方向性的交易也能显著抬高PCR，不能直接解释为“聪明钱都在做空”。[Cboe说明](https://www.cboe.com/insights/posts/how-early-exercise-order-flow-impacts-equity-option-put-call-ratios/)

PCR统计的是合约交易或持仓，不能由此推出买方人数；每笔成交都有买卖双方，买Put、卖Put和组合腿在经济方向上也不同。

### 2. “ETF与期货期权加权”：只恢复了结构，没有恢复权重

[08]01:00–02:24称其为“整个市场ETF和期货的期权PCR的一个加权”；[13]又单独比较50和300的PCR。

两种可能的组合方式是：

```text
比率的加权平均：X_t = Σ_j w_j,t × (Put_j,t / Call_j,t)，Σw=1
先合计再相除：  X_t = Σ_j Put_j,t / Σ_j Call_j,t
```

二者一般不相等。第二式等价于按Call统计量赋权的比率平均；但不能据此推定作者实际选用了第二式。尚缺产品名单、ETF/股指权重、到期月、行权价覆盖、跨合约计量与换月规则。

[13]作者称300触下轨但50未触，因此不能判整体市场见底；这是其50/300联合判读规则，**不是证明50PCR永远领先或等于整个市场PCR的数学结论**。

### 4. IV、VIX、Vega与其他Greeks

视频多次谈“期权贵不贵”、IV变化与权利金，但没有公开完整定价或反演实现。应分别理解：

- **IV**：使某个期权定价模型价格等于市场权利金的波动率参数。标准数学表达为求解`OptionModel(S,K,T,r,q,σ_IV)=OptionPrice_market`。具体模型、利率、分红、报价中间价/成交价、期限与行权方式仍需输入，不能只拿期权价格直接算一个无条件IV。
- **Vega**：`∂OptionPrice/∂σ`，是对IV变化的敏感度；终端常按波动率变动1个百分点报价，要核对单位。它不是IV。[OCC/OIC说明](https://www.optionseducation.org/advancedconcepts/vega)
- **Delta**：`∂OptionPrice/∂S`；**Gamma**：`∂²OptionPrice/∂S²`；**Theta**：期权价格对时间推进的敏感度，按日/年及时间变量方向有不同显示约定。这些是标准定义，视频没有给自己的计算模型或参数。
- **VIX**：Cboe基于SPX期权报价构建的约30天预期波动率指数，是特定市场的指数，不是单只期权IV，也不是Vega。视频没有公开本地同类波动率指数的完整算法。[Cboe VIX说明](https://www.cboe.com/tradable_products/vix/faqs)

所以不能照ASR把“vega=IV=VIX”合并成一项；也不能由“IV偏低”直接推导买期权必然划算，仍需比较未来实现波动、方向、时间价值和报价。

### 5. 期货升贴水：指标被点名，计算口径未公开

[07]04:39–05:38提及追踪期货升贴水，却没有显示完整计算代码。若补充常用定义：

```text
绝对基差 B_t = F_t,T - S_t
相对升贴水 b_t = F_t,T / S_t - 1
简单年化 b_ann = (F_t,T / S_t - 1) × 365 / d
```

这里F为某到期日T的期货价，S为对应现货指数，d为距到期自然日数。**这些只是标明符号的标准模板，不是已恢复的作者原公式**；也有把基差定义为S−F的相反符号。视频未给合约、换月、自然日/交易日、简单/复利年化及分红调整，不能声称已复刻。

## 该体系能说明什么，不能说明什么

**最关键的逻辑边界：拆分上涨组和下跌组的成交，不等于拆分聪明钱和散户。**

这些公式观测的是参与家数、成交分布、持仓类别或波动率定价。它们本身没有机构账户标签、内幕信息标签，也没有“蓝筹/小票”归属。低TRIN可以支持“上涨组相对其家数更活跃”，不能单凭它断言“机构正买入蓝筹”“市场已见底”。

例如，若红盘5%、TRIN_额=0.3，并保持无平盘口径一致，按恒等式上涨额占比约14.93%。这说明上涨组相对其家数份额活跃；同时约85.07%的成交额仍在下跌组。作者由此断言“真正冰点”“可满仓”，多跨了一层未经这些公式单独证明的判断。

同样，TRIN<1不等于绝对放量：若全市场总额大幅萎缩，上涨组成交额可以占比更高、绝对额却更低。要判绝对放量，另需`E⁺_t/E⁺_(t−1)`或历史均额等比较；视频终端的“放量（资金强于宽度）”实为相对份额标签。

[42]图中确有同类样本回测结果，但没有完整样本构造、训练/测试划分、重叠样本处理与择时规则。其显示的比例属于作者回测输出，不能自动理解为未来发生概率或已验证胜率。用户总览图第一档“百分之百胜率”也不是本次核查可证实的事实。
