# A类公式：原画面第二人复核与可复现定义

复核日期：2026-11-12。这里补充并更新 `breadth_audio.md` 的“仅音频”边界；保留旧文件原状以区分证据来源。全部数字都是**视频画面所显示的历史数值**或对这些数值所作算术复核，不代表本次从行情数据库查询的市场事实。

## 1. 阿姆氏 / TRIN：两种写法是同一个公式

来源：[39] `7700876657855420904`，00:48截图 [test39_48.png](frames/test39_48.png)。已人工看图核准：

\[
TRIN=\frac{上涨家数/下跌家数}{上涨成交量/下跌成交量}
=\frac{上涨家数\times下跌成交量}{下跌家数\times上涨成交量}.
\]

画面的两式是**代数等价写法**，不是两套不同的统计算法。该画面使用“成交量”；[49]音频及[54]终端另行确认成交额口径。

记 A、D 为上涨、下跌家数，V+、V−为对应组的成交量，E+、E−为对应组的成交额：

- `TRIN_量=(A/D)/(V+/V−)`。
- `TRIN_额=(A/D)/(E+/E−)`。

V+、V−是把上涨股、下跌股各自的成交量加总；E+、E−对成交额做相同处理。平盘是否计入家数比例的分母，已能由[54]实时版确认：该版**不计入**。

## 2. 宽广度、涨额占比、涨量占比、额价差、量价差：54号实时版可直接恢复

来源：[54] `7706497063014957027`，00:30截图 [54_0030.jpg](frames/54_0030.jpg)，00:58仍展示同一13:44:39快照 [54_0058.jpg](frames/54_0058.jpg)。画面直接显示：

| 字段 | 画面值 |
|---|---:|
| 涨家占比 | 80.89% |
| 涨额占比 | 83.31% |
| 额价差 | +2.42 |
| TRIN_额 | 0.848 |
| TRIN_量 | 1.048 |
| 上涨 / 下跌 / 平盘 | 4381 / 1035 / 159 |
| 有效样本 | 5575（99.9%） |
| 涨量占比 | 80.15% |
| 量价差 | −0.74 |

终端还写有 `TRIN_额<1 表示涨额占比>涨家占比（资金强于宽度）`。该段原始脚本没有打开，但输出值可进行成组交叉校验，足以确认其显示字段的计算定义。

定义：

\[
p=\frac A{A+D},\quad q_E=\frac{E^+}{E^++E^-},\quad q_V=\frac{V^+}{V^++V^-}.
\]

\[
\begin{aligned}
宽广度/涨家占比&=100p\%\\
涨额占比&=100q_E\%\\
涨量占比&=100q_V\%\\
额价差&=100(q_E-p)\quad\text{（百分点）}\\
量价差&=100(q_V-p)\quad\text{（百分点）}.
\end{aligned}
\]

此处百分数表示法应理解为：p取0–1的小数，如0.8089对应80.89%。两种“差”对百分数的显示值直接相减，单位为**百分点**。画面没有给出百分号或bp后缀；音频把这种差称为“基点”不符合该快照的数字关系，报告应保留原话并用正确单位解释。

独立算术复核：

1. `4381+1035+159=5575`，与有效样本一致。
2. `4381/(4381+1035)×100=80.8899556869%`，四舍五入为80.89%。若把159家平盘也放进分母则不可能得到80.89%。
3. `83.31−80.89=2.42`，`80.15−80.89=−0.74`，与两种差完全一致。
4. 由显示值近似复核：`[p/(1−p)]/[q_E/(1−q_E)]≈0.847993`，四舍五入0.848；量口径约1.048310，四舍五入1.048。

所以此前额价差=`涨额占比−涨家占比`的“候选”，已在这版实时输出上升级为**由画面多个字段相互验证的定义**。它不是股价涨幅差，也不是加权指数收益率减等权指数收益率。

适用边界：这项确认只涵盖[54]这一版，不能追溯证明此前所有历史图都使用相同的ST、停牌、新股、缺数、样本范围或平盘口径。文件列表有 `symbols_hs_a.txt`，但未打开内容，不能仅据文件名宣称覆盖了所有A股或具体剔除了哪些股票；截图也没公开零分母和无成交的处理。

### 这些读数的关系：并非彼此独立的四个信号

由TRIN可得：

\[
TRIN_E=\frac{p/(1-p)}{q_E/(1-q_E)},\qquad
q_E=\frac p{p+TRIN_E(1-p)}.
\]

给定宽广度p后，TRIN_额、涨额占比、额价差可以互相换算。因此它们是同一组涨跌分组数据的不同表达，不能算成三份独立证据。量口径同理。`TRIN_额<1`与`额价差>0`在非退化样本下等价。

截图的“放量（资金强于宽度）”是相对家数份额的强弱标签；没有与昨天或历史均量比较，不能直接读成绝对成交额比前日放大。这些读数也没有机构账户身份，不能仅凭它们证明是“聪明钱”或蓝筹资金在买。

## 3. MCL：截图实际为MCL，默认19/39

来源：[41] `7701667092567538511`，04:40截图 [41_0280.jpg](frames/41_0280.jpg)。公式名称以前缀 `MCL` 开头，描述为“宽广度均线化”。**应纠正总览截图中的MCI**；ASR的MCLL、“麦克连百”等也不应当作另外指标。

参数表：

| 参数 | 最小 | 最大 | 默认 |
|---|---:|---:|---:|
| N1 | 2 | 100 | 19 |
| N2 | 2 | 200 | 39 |

逐字核对后的可见源码：

```text
DIF:=ADVANCE-DECLINE;
EMA1:=EMA(DIF,N1);
EMA2:=EMA(DIF,N2);
MCL:EMA1-EMA2;
MAMCL1:EMA1;
MAMCL2:EMA2;
A:0;
```

可复现的计算内容：`DIF_t=A_t−D_t`，`MCL_t=EMA_19(DIF)_t−EMA_39(DIF)_t`。`MAMCL1`、`MAMCL2`直接输出两条指数均线，**不是再做一次均线**；`A:0`只是绘出零线。

该式没有除以上涨/下跌总家数，也没有乘100、归一化或历史分位数。后续看图核查已确认：[42]01:00的图标题是“10-28 各指标历史分位（0=最低，100=最高）”，因此“MCL37%”是MCL的历史分位，而非这段源码直接输出的指标水平。图上红盘率82.5%、评分14.4%、P60 12.3%、P20 13.7%、P250 9.4%同样都是各自的历史分位；不能把82.5%与[41]口述的当日红盘率74%直接比较。分位样本窗口、滚动与并列排名规则未公开，仍不能完整复现历史分位变换。原证据见[42_0060.jpg](frames/42_0060.jpg)。该MCL源码也没有把MCL作时间累加，不能误转录成另一种累加指数。

数学展开：对N期EMA，递推权重为`α=2/(N+1)`；19期为0.1、39期为0.05，`EMA_t=α×DIF_t+(1−α)×EMA_(t−1)`。画面没有展示起始值规则，跨软件复刻时须另行固定初始化和预热期，否则序列前端可能不同。样本家数取自软件`ADVANCE/DECLINE`字段，画面没有进一步展开其市场范围。

## 4. VW-MACD：这里是滚动成交量加权均价之差，不是对EMA再加权

来源：[36] `7699681780400649826`，01:40截图 [36_0100.jpg](frames/36_0100.jpg)。名称 `VW-MACD`；参数表SHORT=12、LONG=26、MID=9，三者最小2、最大200。

逐字核对后的源码：

```text
VC1:=SUM(C*V,SHORT)/SUM(V,SHORT);
VC2:=SUM(C*V,LONG)/SUM(V,LONG);
DIF:VC1-VC2;
DEA:EMA(DIF,MID);
MACD:(DIF-DEA)*2,COLORSTICK;
```

定义收盘价C_t、成交量V_t：

\[
VC_n(t)=\frac{\sum_{j=0}^{n-1}C_{t-j}V_{t-j}}{\sum_{j=0}^{n-1}V_{t-j}},\quad
DIF=VC_{12}-VC_{26},\quad
DEA=EMA_9(DIF),\quad
柱=2(DIF-DEA).
\]

`COLORSTICK`是柱状显示属性；它不改变计算数值。12/26是K线条数，[36]周线用法中对应12/26周，切日线后对应12/26日，不能一律称12日/26日。零成交量分母和EMA初始化未在这段公式里额外处理。它属于量价技术分析补充，不能因为带成交量就声称可以识别持仓者身份。

## 5. 三只ETF合计成交额与20期均线：是作者“证伪国家队”示例

来源：[17] `7693482292580785890`，01:30截图 [17_0090.jpg](frames/17_0090.jpg)。代码注释“宽基ETF资金监测【仅成交额】”。基金代码明确为 **510300、510050、588000**，仅这三只基金，不能写成全部300/50/科创ETF的合计。

逐字核对后的源码：

```text
{宽基ETF资金监测【仅成交额】}
N:=20;
ET300_AMO:="510300$AMOUNT"/100000000;
ET50_AMO:="510050$AMOUNT"/100000000;
ETK50_AMO:="588000$AMOUNT"/100000000;
TOTAL_AMO:=ET300_AMO + ET50_AMO + ETK50_AMO;
AMO_MA:=MA(TOTAL_AMO,N);
TOTAL_AMO,COLORWHITE,LINETHICK2;
AMO_MA,COLORGRAY,DOTLINE;
DRAWTEXT(ISLASTBAR,TOTAL_AMO*0.9,'3只宽基合计成交额(亿)'),COLORWHITE;
```

`AMOUNT`为成交额字段；这里每只都除以一亿后再相加，绘制单位为亿元。数学式：`TOTAL_t=(E_510300,t+E_510050,t+E_588000,t)/10^8`，`AMO_MA_t=(Σ_{j=0}^{19}TOTAL_(t−j))/20`。20是K线周期数；作者此集讲每天数据，所以该例为20日。线色、线宽、虚线、最后一根K线的文字注记均为显示属性。

这段图只是三只基金的二级市场成交活跃度，源码没有申购赎回净额或投资者身份字段，不是国家队净买入计算公式；作者展示它的目的本来就是反驳用ETF成交量识别国家队。
