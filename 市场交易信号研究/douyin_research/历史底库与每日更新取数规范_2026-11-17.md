## 3. 建议你一次性手动导出的均线底库

在 iFinD 终端的历史行情／数据提取功能导出。不同终端版本的菜单名称可能不同；下面给的是字段与参数要求，不编造尚未核实的函数代码。保留原始表头、单位、复权选项和提取日期，便于验收。

### 股票清单：保存完整名单，计算时再过滤

导出截至目标日T的**全部沪深A股**，保留ST、停牌股票，排除北交所、B股、基金、可转债。保留ST的目的是支持含ST MCL及未来摘帽股票的均线历史；实际均线分母仍剔ST。

清单至少含：证券代码、简称、交易所／证券类别、上市日期、T日ST／*ST状态、T日交易状态。股票代码保留六位及`.SH`／`.SZ`后缀。

不要只导出当前可交易的非ST股票后永远使用这份固定名单。每日需纳入新上市股票，并处理ST变更、停复牌、退市和代码变更。此底库用于**从T日起的当前均线与后续更新**；若还要回测T之前的全市场均线比例，须另补历史上市退市成员及历史ST状态，当前名单不能替代。

### 历史价格：每只至少250根实际日K

建议先导出截至T的**最近500个市场交易日**作为抓取范围，再逐股检查实际日K根数。这个500日是操作缓冲，不是充分性保证：长期停牌老股若仍不足250根，继续向前补；新股导出上市以来全部数据，不虚构不足的历史。

每一行是“日期＋股票代码”，字段如下：

| 字段 | 要求／用途 |
|---|---|
| 交易日期、股票代码 | 联合唯一；代码存文本，避免丢前导零 |
| 不复权收盘价 | 元；保留源精度 |
| 前复权收盘价 | 元；**同一次导出固定基准日T**，保留元数据；用于直接复算和核对复权因子 |
| 复权因子及其定义 | 同一供应商、同一算法；必须确认乘除方向及基准。不能只给名称不明的“复权值” |
| 不复权成交量 | **股**；若源单位是手，需标明并换算 |
| 成交额 | 元；不以万元、亿元字段混入 |
| 交易状态 | 正常／全天停牌等，须区分缺数据与停牌 |

历史停牌日可以不导出；如终端补行，须带明确状态及量额，不让沿用的前收被当作一根新日K。空价格、空成交量不能自动填零。实际日K按已确认存在有效成交的股票日记录识别；缺字段先补证据，不静默删除。

每只股票维护最近250根合格日K，MA20、MA60分别取最近20、60根。当天股票先通过沪深A股、非ST、非全天停牌、非零成交的筛选，再按该股票是否有足够历史进入N20、N60、N250。ST过滤作用于观察日的股票池；一只今天合格的股票，其过去ST期间真实发生的日K不应从自身均线窗口里删去。

```text
比例_n = 100 × 当日合格且同口径价格 > MA_n 的股票数
                 ÷ 当日合格且具有至少 n 根实际日K的股票数
```

严格“大于”；等于均线不计入分子。三个分母分别计算。老股字段缺失不能冒充“上市不足周期”。

### 为什么需要复权因子

前复权历史在除权除息后可能变化，所以“先保存前复权历史、以后只追加每天一个收盘价”**不能保证持续正确**。

如果导出的累积因子F已验证满足 `前复权价(s;T)=原价(s)×F(s)/F(T)`，则保存 `原价(s)×F(s)` 即可滚动维护。目标日的前复权均线为：

```text
MA_n(T) = 最近 n 根实际日K的 [原价(s)×F(s)] 的平均值 ÷ F(T)
```

同一正数基准下，站上均线的比较不会改变。**这条计算只有在供应商因子定义核验通过后启用，不能未经检查套到名称相似的字段上。** 初次应抽查普通股票、除权除息股票、历史停牌股票及新股；同时核对前复权价格与均线，差异接近“是否站上”临界值时单独标记。

如果终端无法提供可验证的因子，可先用同一基准日前复权历史初始化；以后遇到除权除息，对受影响股票重新导出最近250根实际日K。这样仍无需每天重新取全市场全部历史，但不能承诺永远只取每日收盘价。供应商更正旧数据时也需修订相应窗口。

## 4. 每日收盘后需要更新哪些截面

股票清单与日行情要覆盖**当日全部沪深A股，包含ST**，不能仅请求底库中已有代码。一次完整截面同时服务多个指标，再按各自口径过滤。

| 每日字段 | 作用 |
|---|---|
| 日期、代码、简称、证券类别、交易所、上市日期 | 完整名单、代码匹配、新股识别 |
| 当日ST／*ST状态、交易状态 | 均线等剔ST；含ST MCL保留ST；正确识别全天停牌 |
| 不复权收盘价、交易所当日参考昨收、原始精度涨跌幅／涨跌额 | 涨跌方向；除权日不能简单用昨天文件里的收盘价替代当日参考价；不按四舍五入后的显示涨跌幅分组 |
| 不复权成交量、成交额 | 判断有效成交、计算量／额阿姆氏与额价差 |
| 当日复权因子 | 更新均线价格基准；定义需与历史库一致 |
| 当日流通A股股本 | 普通换手率=成交股数÷流通A股股本；不使用总流通股或自由流通股替代 |
| 可选：同口径前复权收盘价、MA20／60／250 | 与本地均线抽检；不能用筛选服务无参数均线强行填缺 |

仅为MCL更新时，不必每天取全部股票：从**同一张iFinD报表**取当天A、D、U即可。它避免了每天逐股聚合的工作量。以后若改为从完整截面自己聚合，先与报表重叠核验涨跌方向，尤其是除权日、新股和停复牌日；未核对一致前不切换系列来源。

日终值只在当日行情完成更新后验收：日期必须是T，记录必须覆盖当日名单，不能拿T−1旧值当T。发布前检查缺代码、重复代码、单位、零成交／停牌证据、A+D+U合计、股票池变化和复权异常。返回“success”不替代这些检查。

### 每日MCL怎么续算

已保存到2026-11-16的两条EMA及源数据。新交易日只需新增该日A、D、U，按上面的递推式更新。当前更新程序保留完整底库，并在合并新行后重算，便于处理迟到修订；无需重新从外部拉取全部历史。

已具备的保护包括：重复下载同一天不重复计数；禁止混入剔ST口径；缺交易日拒绝出结果；历史数字冲突需核验后显式更正；更正后重算后续EMA。增量计算与一次性计算一致，六项相关检查已通过。

当前历史只有291天。若要研究更早时期，仍从同一张报表向前导出；建议在拟研究起点前另留至少200次递推作预热。预热长度是工程选择，不是保证恢复博主起点或证明交易有效性。

### 午盘可作为额外快照

11:30保存上午最后价、上午累计成交量／额及相对当日参考昨收的涨跌方向。使用完整上午累计值，不能把累计数再次相加。含ST MCL的午盘还需ST股票；已验收的5,027家非ST午盘快照本身不满足这个新增股票池。

午盘MCL从**前一交易日日终EMA**临时递推；收盘时仍从同一个前日日终状态计算，不能把午盘当成额外一日。午盘均线也只生成当日临时日K，收盘替换该日临时值，不增加第二根日K。
