## 一、完整源码（逐字转录）

```pascal
公式名称：MCL麦克联摆
公式描述：宽广度均线化
公式类型：（画面未显示，按输出线型判断为副图指标）

参数表：
  参数   名称    最小      最大      缺省
   1     N1     2.00    100.00    19.00
   2     N2     2.00    200.00    39.00
   3     —       —        —         —
   4     —       —        —         —

DIF:=ADVANCE-DECLINE;
EMA1:=EMA(DIF,N1);
EMA2:=EMA(DIF,N2);
MCL:EMA1-EMA2;
MAMCL1:EMA1;
MAMCL2:EMA2;
A:0;
```

代码区共 7 行，末行为 `A:0;`，其下方被人物画面遮挡，无更多语句。

## 二、逐行解释

| 代码行 | 含义 |
|---|---|
| `DIF:=ADVANCE-DECLINE;` | `ADVANCE` = 上涨家数、`DECLINE` = 下跌家数（均为通达信内置的大盘统计函数）；二者相减得到 **A−D 线**（涨跌家数净差），即博主所说的「宽广度」原始序列 |
| `EMA1:=EMA(DIF,N1);` | 对 A−D 线取 **N1 = 19 日**指数移动平均（快线） |
| `EMA2:=EMA(DIF,N2);` | 对 A−D 线取 **N2 = 39 日**指数移动平均（慢线） |
| `MCL:EMA1-EMA2;` | 快线减慢线，得到振荡器主体——这就是「**宽广度均线化**」的实质：把涨跌家数差做平滑后取动量 |
| `MAMCL1:EMA1;` | 单独输出快线，便于叠加观察 |
| `MAMCL2:EMA2;` | 单独输出慢线 |
| `A:0;` | 用常量画一条 **0 轴**水平参考线（通达信中以 `A:0` 输出零轴） |

## 三、与经典 McClellan Oscillator 的对应关系

经典定义：

```
McClellan Oscillator = EMA19(上涨家数 − 下跌家数) − EMA39(上涨家数 − 下跌家数)
```

博主公式的缺省参数 **N1 = 19、N2 = 39**，与经典定义完全一致；结构亦完全一致（同为 A−D 线的快慢 EMA 之差）。

**结论**：`MCL` 就是**麦克莱伦振荡器（McClellan Oscillator）**的通达信实现。此前语音转写出现的「麦克连百」「麦C连百」「MCL 麦克连百」「Mac 200」等，均系同一名称的误听或误写；画面规范写法为「**MCL麦克联摆**」。

结构上与 MACD 同构——都是快慢 EMA 之差，区别在于 MACD 的输入是价格，MCL 的输入是涨跌家数净差。这解释了博主为何称其为「宽广度均线化」，并把它与阿姆氏并列为「观察市场宽广度最好用的两个东西」。

## 四、博主的用法口径（画面与口述）

1. **定位**：与阿姆氏指标并列，「最好用的两个东西，一个是 MCLL，一个呢就是阿姆士」[41 5:00]。
2. **触发场景**：9-22 的转折点「并不是阿姆士发出来的，而是市场的宽广度和 MCL 发出来的信号」[41 3:00]。
3. **实际判读采用历史分位，而非固定阈值**：2026-10-28 的画面显示「MCL 37%」，标题为「各指标历史分位（0=最低，100=最高）」，博主据此判断「它是非常的弱的，只有 37%」，并计入当期评分 14.4%（同期红盘率 82.5%、P60 12.3%、P20 13.7%、P250 年线 9.4%）[42 t=64.73]。
4. **他只公开算法、不公开用法**：「MCL 这个是非常好用的……用法呢你可以去网上搜索网上学学，这也是公开的东西」[41 5:00]；同一期反复强调「算法是算法，用法是用法」。

## 五、外部参照（非博主口径，供校准）

经典 McClellan Oscillator 的常见判读：读数 > +70 视为超买、< −70 视为超卖；上穿 0 轴转强、下穿 0 轴转弱；与指数价格背离时提示转折。

**这些阈值博主未在画面中出现**，其自有口径是「历史分位 + 纳入评分」，两者不可直接混用。若按经典阈值使用，需自行回测标定。

## 六、可复现条件与注意事项

1. **数据依赖**：公式完全依赖通达信的 `ADVANCE` / `DECLINE` 两个内置大盘统计函数，需下载完整日线数据；数据缺失时输出为空。
2. **指数口径未说明**：`ADVANCE`/`DECLINE` 取哪个市场（上证、深证或全 A）会影响数值量级，博主未在画面或口述中指明；其「市场宽广度」口述为**全市场涨跌家数**。
3. **参数边界**：公式限制了 N1 ≤ 100、N2 ≤ 200、最小值 2，超出范围无法保存。
4. **平盘与 ST 处理未说明**：博主在阿姆氏相关视频中提过「平盘怎么处理、ST 怎么处理会导致数值差异」，但未说明 MCL 是否做同样处理。
5. **输出线型**：`MCL`/`MAMCL1`/`MAMCL2` 均为默认线型输出，代码中未指定 `COLORSTICK`，即画面上的 MCL 是**曲线而非柱状**。
