## 规则

0. **一条命令同步两个目标（推荐）**：
   ```bash
   cd /Users/yangguang/WorkBuddy/市场交易信号研究/douyin_research
   ./sync_all.sh              # ① Codex 工作区 ② Workbuddy 分类库

   ./sync_all.sh codex        # 只同步 Codex
   ./sync_all.sh archive      # 只归档分类库
   ```

1. 源端每次新增以下内容后，**立即**执行一次增量同步（无需人工提醒）：

   - 报告与数据（根目录 `*.md`、`*.csv`、`关键截图_*.jpg`）

   - 转录与定位中间产物（`visual_transcripts/`、`visual_scan/`、`refine/`、`times/`）
2. 同步命令（源端执行）：
   ```bash
   cd /Users/yangguang/WorkBuddy/市场交易信号研究/douyin_research
   ./sync_to_codex.sh
   ```
3. 默认排除：`.DS_Store`、`frames_test/`、`frames_probe/`、`frames_v2/`、`frames_timing/`、`work_crops/`
   - `./sync_to_codex.sh --with-crops` 可连 `work_crops/` 一起传
   - `./sync_to_codex.sh --dry-run` 只预览差异
4. 每次同步自动向 `_同步日志.md` 追加一行（时间、传输文件数、体积、视频数、逐字稿数、关键截图数、根目录文档数、目标总体积）。

## 关键纪律

- **不删除目标端文件**：用 rsync 增量（无 `--delete`），Codex 侧自己的分析产物（如 `ma_native_retry_2026-11-18/`、`formula_audit/`、`full_validation_2026-11-17/`）不受影响。
- **不覆盖结论**：源端同名文件更新会覆盖（如 `videos.json` 从 54 条扩到 59 条），但 Codex 侧新建的目录不会被触碰。
- **ASR 失败时**：先 `./extract_audio <mp4> <m4a>` 导出纯音轨存 `audio_new/`，待服务恢复补完逐字稿后再同步，避免留下"有视频无文字"的断档。

## 归档库同步（WorkBuddy → Documents/Workbuddy 分类库）

**生效日期**：2026-11-18
**源**：同上的 `douyin_research/`（工作根，脚本与数据都留在此处）
**目标**：`/Users/yangguang/Documents/Workbuddy/`（一级按类型、二级按项目、三级保留原始子目录）

```bash
cd /Users/yangguang/WorkBuddy/市场交易信号研究/douyin_research
./archive_to_workbuddy.sh            # 增量硬链接（幂等，可反复跑）
./archive_to_workbuddy.sh --dry-run  # 只统计待新增数量
```

- **硬链接而非复制**：同一 inode 两个入口，不占额外空间。修改/删除任一入口同时作用于同一 inode。
- **不是目录绑定**：原路径新增文件不会自动出现在归档库，必须再跑一次脚本。
- **不该在分类库里跑脚本**：`download_videos.py`、`validate_videos.py`、`sync_to_codex.sh` 等按脚本自身位置定位数据，搬到分类目录会因数据不同级而失败。
- 文件类型映射：`*.py/*.js/*.sh/*.swift/*.log` → `01_代码`；根目录 `*.md` → `02_说明文档`；`*.csv/*.json/*.txt` 及 `*_20xx-xx-xx/` 数据快照 → `03_数据源`；`videos/`、`audio/` → `04_视频`；`transcripts/` → `05_转写稿`；`关键截图_*.jpg` → `06_报告与图表`；`frames/`、`sheets/`、`work_crops/` 等 → `07_中间产物`。
- 脚本末尾会提示**未映射目录**，出现提示需补进 `link_dir` 规则，否则该目录不会被归档。

## 已修的坑

- `du -sh <含中文绝对路径>` 在 macOS 上可能返回 **0B**（Unicode 归一化问题）。`sync_to_codex.sh` 已改为 `cd` 进目标目录再 `du -sh .`。
- 归档脚本原来靠 `ln`/rsync 的增量计数上报，会误报「硬链接 0 个」。已改为**归档前后按库内实际文件数快照差值**统计。
