### 4.1 TRIN / 阿姆氏公式卡（完整）

**画面**：[39] t=48.40 / 60.40，白底公式卡（按原始换行抄录）

```
26-10-26
TRIN = (上涨家数 /
下跌家数) / (上涨成
交量 / 下跌成交量)
或
TRIN = (上涨家数 ×
下跌成交量) / (下跌
家数 × 上涨成交量)
```

连读：

```
算法①  TRIN = (上涨家数 ÷ 下跌家数) ÷ (上涨成交量 ÷ 下跌成交量)
算法②  TRIN = (上涨家数 × 下跌成交量) ÷ (下跌家数 × 上涨成交量)
```

**关键更正**：两式**代数完全等价**（② 是 ① 的分子分母同乘展开），并非上一轮依据口述推断的「两种不同算法、第二种仅在屏幕展示未公开」。画面只给出这一张公式卡。口述 [39] 所谓「两种算法都是可以的」应理解为两种**书写/实现形式**，或指成交额口径 vs 成交量口径（见 4.2）。

```
           | 有效 5575 (99.9%) -> 放量(资金强于宽度)

           | TRIN_额<1 表示涨额占比>涨家占比(资金强于宽度)
```

**由画面数值精确反推（全部验算吻合）**：

| 指标 | 公式 | 画面验算 |
|---|---|---|
| **额价差** | `涨额占比 − 涨家占比`（百分点） | 83.31 − 80.89 = **+2.42** ✓ |
| **量价差** | `涨量占比 − 涨家占比`（百分点） | 80.15 − 80.89 = **−0.74** ✓ |
| **TRIN_额** | `(涨家数 ÷ 跌家数) ÷ (涨额占比 ÷ 跌额占比)` | (4381/1035) ÷ (83.31/16.69) = 4.2329 ÷ 4.9916 = **0.848** ✓ |
| **TRIN_量** | `(涨家数 ÷ 跌家数) ÷ (涨量占比 ÷ 跌量占比)` | 4.2329 ÷ (80.15/19.85) = 4.2329 ÷ 4.0378 = **1.048** ✓ |
| **判读** | `TRIN_额 < 1` ⇔ 涨额占比 > 涨家占比 ⇔ 资金强于宽度（放量） | 画面自述 ✓ |

这解释了口述中「成交量口径与成交额口径混用」的疑问：**同一套 TRIN 公式分别代入成交额占比与成交量占比，得到 TRIN_额 与 TRIN_量 两条序列**；额价差/量价差则是相应占比与涨家占比之差。上一轮报告「额价差定义与算法未公开」据此可结案。

> 订正低清扫描误读：脚本是 **PowerShell `.ps1`** 不是 `.py`；数据文件 `symbols_hs_a.txt` 不是 `symbols_tbl.txt`；终端字段是「涨家占比 / 涨额占比 / TRIN_额 / TRIN_量 / 量价差 / 涨量占比」，**没有**「TRIN_瞬」「高走占比」。微信画面 [54] t=96.40 另提到「用 PowerShell 抓通达信 API」「其实用 Python 更完美」。

### 4.3 VW-MACD 通达信源码（完整）

**画面**：[36] t=103.80，指标公式编辑器；参数与读数见 t=88.00 / 89.60 / 96.40 / 120.40

```pascal
公式名称：VW-MACD        公式类型：成交量型     画线方法：副图
参数表：
  1  SHORT   最小 2.00   最大 200.00   缺省 12.00
  2  LONG    最小 2.00   最大 200.00   缺省 26.00
  3  MID     最小 2.00   最大 200.00   缺省  9.00

VUC1:=SUM(C*U,SHORT)/SUM(U,SHORT);
VUC2:=SUM(C*U,LONG)/SUM(U,LONG);

DIF:VUC1-VUC2;
DEA:EMA(DIF,MID);
MACD:(DIF-DEA)*2,COLORSTICK;
```

画面「用法注释」区（部分被字幕遮挡）写明：

```
VUC1 = (收盘价 × 成交量(手)) 的 SHORT 日累和 / 成交量(手) 的 SHORT 日累和
VUC2 = (收盘价 × 成交量(手)) 的 LONG  日累和 / 成交量(手) 的 LONG  日累和
输出 DIF : VUC1 − VUC2
输出 DEA : DIF 的 MID 日指数移动平均
输出 平滑异同平均线 : (DIF − DEA) × 2, COLORSTICK
```

即 **VUC1/VUC2 是成交量加权移动均价（VWMA）**，用 12 日与 26 日 VWMA 之差替代传统 MACD 的 EMA12−EMA26，再做 9 日 EMA 平滑。这解释了口述「VWMACD 是量价关系的图形展示，不是简单 MACD」[36]。

**同一画面的其他指标参数**：`VW-MACD(12,26,9)`（实例 DIF 62.55 / DEA 67.16 / MACD −47.60 等）、`BOLL(20)`（BOLL 3250.64 / UB 3407.75 / LB 3093.53）、`CCI(14)`（CCI 75.85）、一目均衡表「先行带A: 3234.44 / 先行带B: 3182.05」。
