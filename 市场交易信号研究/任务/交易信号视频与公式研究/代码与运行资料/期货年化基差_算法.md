## 一、结论：四步计算链

```
① 基差(点)   = 期货主力收盘 − 指数收盘
② 基差率     = 基差 ÷ 指数收盘
③ 年化基差率 = 基差率 × 365 ÷ 剩余自然日
④ N日分位    = 年化基差率在过去 200 个交易日中的百分位（0~100%）
   分位档    = 按分位五分档（低分位/偏低/中性/偏高/高分位）
```

**核心公式（③）**：

```
年化基差率 = (期货主力收盘 ÷ 指数收盘 − 1) × 365 ÷ 剩余自然日 × 100%
```

等价于 `基差率 × 365 ÷ 剩余自然日`，年化天数取 **365 自然日**（不是 250 交易日），分母为**剩余自然日**。

## 五、分位与分档口径（观测推断）

由表内 H、I 两列的对应关系可复原分档：

| N日分位 | 分位档 |
|---|---|
| 98.3% / 90.0% / 88.3% | 高分位 |
| 73.3% / 66.7% / 61.7% | 偏高 |
| 53.3% / 60.0% | 中性 |
| 20.0% | 偏低 |
| 8.3% / 0.0% | 低分位 |

据此推断五档阈值为：**<10% 低分位｜10–40% 偏低｜40–60% 中性｜60–80% 偏高｜≥80% 高分位**。样本窗口为 **200 个交易日**（表标题明示）。

> 分位方向：**年化基差率越高（越接近 0 或转正），分位越高**。因此「高分位」表示当前贴水相对历史**偏浅**；「低分位」表示贴水相对历史**最深**。

## 六、博主 11-17 的判读（画面硬字幕）

画面字幕依次为：

- 「至少在股指期货那边来看啊」
- 「期货那边它的价格比现货要低得特别的多」
- 「它的贴水非常严重」
- 「那这个是**年化的基差率**」
- 「在**比较高的状态**」
- 「也就是它下面**还是有空间的**」

结合分位表可还原其逻辑：当期年化基差率为负（贴水），但**历史分位处于偏高/高分位（约 70%–98%）**，即贴水程度相对历史偏浅，故判断下行空间尚未走完。这与「贴水非常严重」（绝对水平）并不矛盾——**绝对值深、相对分位高**，两句话分别对应基差率与分位两个维度。
