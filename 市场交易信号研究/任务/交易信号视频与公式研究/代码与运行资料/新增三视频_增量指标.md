### 增量点

1. **额价差单位明确为 `pp`（百分点）**——此前仅能从终端数值反推，现由画面直接给出 `+26.09pp`。
2. **新指标「人均成交额」**：备注写「人均成交额是下跌股的 2.9 倍」。可验证为
   `人均成交额比 = (涨额占比 ÷ 涨家占比) ÷ (跌额占比 ÷ 跌家占比) = 1 ÷ TRIN_额`
   代入 39.34% / 65.43% → (65.43/39.34) ÷ (34.57/60.66) = **2.92 ≈ 2.9** ✓，且 1 ÷ 0.34 = 2.94 ✓。
   即它与 TRIN 互为倒数关系，是同一信息的直观化表达。
3. **MCL 的盘中用法被标注为「MCL缩」**：宽广度 39.34% 且指数红盘时，MCL 处于萎缩下行，作为「反弹不健康」的第一条证据。

### 系统构成的权威表述

> 「我之前提到阿姆士，只是说明阿姆式是我整个量能宽广度系统的一个观察点。我的**全部宽广度、量能观察系统包含了 MCL、Mac连百，除此之外还包含了涨价占比、涨额占比、额价差以及阿姆什**，它是一个完整的分析系统，在不同的市况有不同的分析的模式，所以不存在一招鲜，都要综合来看。」[56 2:25]

> 逐字稿「涨价占比」为语音误听，画面字段为「**涨家占比**」。

这是博主首次在口述中把「量能宽广度系统」的成员逐项点名，与画面字段完全对应，可作为该子系统的权威清单。

## 三、计算关系的交叉验证（全部吻合）

| 关系 | 验算 | 结果 |
|---|---|---|
| 额价差 = 涨额占比 − 涨家占比 | 28.84−15.81=**13.03**；23.12−13.88=**9.24**；24.47−20.75=**3.72≈3.73** | ✓ 三列全中 |
| 量价差 = 涨量占比 − 涨家占比 | 以 11-16 反推涨量占比 = 20.75+13.41 = 34.16% | ✓ 自洽 |
| TRIN_额 = (涨家÷跌家) ÷ (涨额÷跌额) | 11-16：(1134/4332) ÷ (24.47/75.53) = 0.2618/0.3240 = **0.808≈0.81** | ✓ |
| TRIN_量 = (涨家÷跌家) ÷ (涨量÷跌量) | 11-16：0.2618 ÷ (34.16/65.84) = 0.2618/0.5188 = **0.505≈0.5** | ✓ |
| 人均成交额比 ≈ 1 ÷ TRIN_额 | 1 ÷ 0.34 = **2.94 ≈ 2.9** | ✓ |

结论：本次新增的两张表，与上一轮从 [54] 实时终端反推出的额价差/量价差/TRIN 双口径公式**完全一致**，互为独立验证。至此该组公式可视为**确证**。
