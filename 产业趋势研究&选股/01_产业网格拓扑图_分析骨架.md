# 产业网格拓扑图 · 分析骨架（V1 模板）

> 用途：把博主（及你自己）的产业研究装进一个可复用、可跟踪、可落地到 A 股选股的结构里。
> 三条主线：**① 找下一个卡脖子环节 → ② 卡脖子的供给/扩产能力 → ③ 下游需求与跟踪**。
> 使用方式：先用此骨架理解方法论；待转写稿到位后，把博主的具体观点/案例/指标填入《02_产业案例填充模板》。

---

## 〇、什么是"产业网格拓扑图"

把一条产业链画成"网格 × 拓扑"两层结构：

- **拓扑层（纵向，价值链方向）**：上游资源 → 中游材料/设备/零部件 → 下游模组/系统 → 终端应用。看"价值往哪流、利润卡在谁手里"。
- **网格层（横向，每个环节的属性打分）**：对每个环节用统一维度打分（国产化率、集中度、扩产周期、议价权、需求弹性…），形成一张可比的"格子"。

> 卡脖子环节 = 拓扑上"价值高、可替代性低"的位置 ∩ 网格上"国产化率低 + 扩产慢 + 议价权强"的格子。
> 投资机会 = 卡脖子环节里"正在被国产玩家突破 / 即将量产兑现"的那一格。

## 一、主线①：怎么找拆解路径上"下一个卡脖子环节"

### 1.1 拆链：先把产业链画到"颗粒度足够细"
- 从终端产品倒推：终端 → 系统 → 模组 → 零部件 → 材料 → 设备 → 原料。
- 每往上拆一层就问："这一层里，谁的东西最难做、最难替代？"
- 颗粒度标准：拆到"能对应到一个具体可买的上市公司/细分品类"为止（如不是"半导体"，而是"光刻胶用 PSPI / ArF 光刻胶"）。

### 1.2 卡脖子环节的 6 个识别信号（满足越多越像）
| 信号 | 含义 | 怎么验证 |
|---|---|---|
| ① 国产化率低 | 当前主要靠进口/海外垄断 | 海关进口金额、行业国产化率数据、招股书"竞争格局" |
| ② 技术壁垒高 | 工艺/专利/Know-how 难复制 | 良率差距、研发投入、专利布局、客户认证周期长 |
| ③ 供给集中 | 全球少数几家把持 | CR3/CR5、龙头市占率 |
| ④ 议价权强 | 涨价能传导、毛利率高且稳 | 毛利率水平与波动、产业链中利润占比 |
| ⑤ 价值量占比高 | 在终端 BOM 里占钱多 | 拆解 BOM 成本结构 |
| ⑥ 扩产慢 | 产能起不来（设备/认证/资金） | 扩产周期、在建工程、资本开支 |

### 1.3 "下一个"卡脖子的动态判断（前瞻性，最值钱的部分）
卡脖子环节会随技术迭代而**转移**。判断"下一个"要看三类驱动：
- **技术路线切换**：新一代技术导致瓶颈环节转移（例：算力从"先进制程"→"先进封装/HBM"→"光模块/铜连接"→散热/电源）。
- **政策/制裁倒逼**：被卡的环节 = 国产化最迫切、确定性最高的方向（看"实体清单""自主可控"清单）。
- **下游放量倒逼上游**：终端渗透率快速提升时，最先紧缺的上游环节（看渗透率 S 曲线拐点）。

> ✅ 落地动作：对每条链画一张"卡脖子迁移图"，标注【过去瓶颈 → 当前瓶颈 → 下一个潜在瓶颈】，并标注触发条件。

## 二、主线②：卡脖子环节的"供给 / 扩产能力"怎么看

> 卡脖子之所以是机会，是因为"国产替代 + 量价齐升"。但能不能兑现，取决于供给端能不能起来、起多快。

### 2.1 供给格局
- 全球供给：海外龙头是谁、市占率、产能在哪、有没有扩产或转移意愿。
- 国产供给：哪些公司在做、处在"送样/认证/小批量/放量"哪个阶段（**这是 A 股选股最关键的进度条**）。
- 进入壁垒：客户认证周期（半导体/汽车常 1–3 年）、设备可得性、专利墙。

### 2.2 扩产能力（决定弹性和节奏）
| 维度 | 要问的问题 | 数据来源 |
|---|---|---|
| 扩产周期 | 从决定扩产到达产要多久？ | 行业经验值、公司公告 |
| 资本开支 | 是否在加大 Capex？在建工程趋势？ | 财报 Capex、在建工程 |
| 产能利用率 | 现有产能是否满产（满产才有扩产动力/涨价基础） | 公司披露、行业数据 |
| 设备/原料约束 | 扩产卡在上游设备或某种原料吗？ | 上游设备龙头订单、原料价格 |
| 良率爬坡 | 新产能良率爬坡速度（决定有效供给） | 公司交流、产业链调研 |

### 2.3 供给侧的"反身性"提醒
- 供给太容易起来 → 容易过剩、价格战（不是好的卡脖子，例：部分锂电环节）。
- 供给起不来 → 持续紧缺、涨价（好的卡脖子，但要防"伪需求"）。
- ✅ 理想标的：**需求确定向上 + 供给有壁垒、扩产慢 + 国产玩家正好卡在放量拐点**。

## 三、主线③：下游客户的需求情况，怎么研究、怎么跟踪

> 需求是"1"，供给和格局是后面的"0"。需求证伪了，再好的卡脖子也没用。

### 3.1 需求研究三层
1. **需求空间（有多大）**：终端市场规模 × 渗透率 × 单位价值量。用 S 曲线判断渗透率处于"导入/加速/成熟"哪一段。
2. **需求节奏（什么时候来）**：下游扩产/排产/招标节奏、新产品发布节奏、政策补贴节奏。
3. **需求质量（真还是假）**：是真实终端拉动，还是渠道囤货/抢装/补库存的伪需求。

### 3.2 怎么跟踪需求（建立"高频指标看板"）
按"离终端远近"分三类指标，越靠左越前瞻、越靠右越确认：

```
前瞻指标            →     中观指标          →      确认指标
(领先,但噪声大)            (产业链中段)            (滞后,但确定)
─────────────────────────────────────────────────────────────
· 下游龙头资本开支         · 上游材料/设备订单       · 月度产销量/出货量
· 大客户新品发布/规划      · 关键零部件价格/交期      · 公司季度收入/订单
· 招标/中标公告           · 开工率/稼动率           · 渗透率官方数据
· 政策/补贴文件           · 库存周转                · 海关进出口数据
· 海外龙头业绩指引        · 排产/排单(产业链调研)    · 月度价格(百川/wind)
```

### 3.3 跟踪频率与动作
- 每月：更新产销量、价格、海关数据 → 看是否符合"放量假设"。
- 每季：跟踪龙头 Capex、订单、毛利率 → 验证"扩产/涨价"逻辑。
- 事件驱动：大客户发布会、招标、政策文件 → 调整节奏判断。
- ✅ 落地动作：每条产业链建一个"需求跟踪指标表"（见《03_AStock跟踪指标看板》），每月打钩更新，逻辑被证伪就出，被强化就加。

## 四、从框架到 A 股选股的"落地漏斗"

```
第1层  选链：渗透率处于加速期 + 国产化迫切的产业链
        ↓
第2层  定位：在链上找"卡脖子格子"(6信号打分)
        ↓
第3层  选供给:格子里找"正处于认证→放量拐点"的国产公司
        ↓
第4层  验需求:用高频指标确认下游需求真实且向上
        ↓
第5层  估值&节奏:看市场是否已price in,等订单/业绩兑现催化
        ↓
        建仓 → 持续用指标看板跟踪 → 逻辑证伪即退出
```
