# 11 · 单股打分卡：景气/主题判别 + 景气度打分

> 核心诉求：**给一只股 → 判断现在交易的是景气还是主题 → 给景气度打分。**
> 可用资源（四条输入管）：① **iFinD**（硬数据/价量/估值/排名）② **舆情搜索 agent-reach**（热度/情绪/小作文出处）③ **卖方路演材料**（如唯特偶推荐材料）④ **买方群小作文**。
> 关键认知：③④ 是双刃剑——既是景气数据、又是主题加工/数据PS 的载体。所以**先过"信源处理闸门"，再决定它计入景气分还是主题分**。

---

## Step 0 · 信源处理闸门（卡的灵魂，所有定性材料先过这道）

> 路演材料/小作文/纪要/舆情，**不分青红皂白计入景气分 = 自己把主题当景气加 = 被复合收割**。每条定性输入先过五问：

1. **可验证性**：它讲的是"已发生、可被 iFinD/产业数据交叉验证的数据"，还是"不可证伪的远期叙事/拉久期"？（前者→景气，后者→主题）
2. **信源手数**：一手财报/公告 > 卖方路演 > 买方小作文 > 自媒体转引 → 定可信度权重。
3. **先图还是先数据**：这材料是在解释一个"价已先动"的走势，还是"数据先变了"？
4. **数据PS红旗**：单一信源？主营跨界/转型？业绩发布节奏异常？海外空白区先涨再传回国内？
5. **拆小作文三问**：结构件还是功能件？哪个等级、什么工种？替代它的更便宜还是更贵？

> **过闸**（硬、可验证、多手、能交叉）→ 计入**景气分**。
> **不过闸**（软、远期、单一信源、先图后逻辑）→ 计入**主题分 + 红旗**。

## 输出① · 景气 vs 主题 判别表

> 每条信号给"景气票"或"主题票"，最后汇成"景气 X 成 / 主题 Y 成"。带 ★ 的是最锋利、最难被话术骗的。

| 类 | 信号 | 数据源 | 量化口径 | 唯特偶实测(2026-06) |
|---|---|---|---|---|

| 景气 | ★顺价传导 | iFinD毛利 + 产业价格 | 毛利增速 > 营收增速？毛利率方向？ | 毛利增速38.8%>营收27.4%，毛利率17.7%>TTM15.7% → **顺价票** |

| 主题 | 舆情热度/情绪词 | agent-reach | 讨论量 + "国产替代/卡脖子/万亿"词频 + 散户平台占比 | **待舆情搜索**（你来跑/我来跑） |

## 输出② · 景气度打分（0–100，剥离股价情绪，只评"景气本身强不强"）

> 注意：**这跟"现在是否在交易景气"是两件事**。唯特偶景气度底子分不低，但当前交易主题——别混。
> 景气度 = "需求×供给×可持续×位置" 的加权。每项 0–20（位置类反向）。

| 维度 | 看什么 | 数据源 | 权重 | 唯特偶 |
|---|---|---|---|---|
| 业绩兑现强度 | 营收/毛利/净利增速+加速度 | iFinD | 20 | 强(16/20)：+27/+39/+36、毛利率扩 |
| 顺价可持续 | 上游涨价能否传到下游毛利 | iFinD毛利 + 锡价 + SMT订单 | 20 | 中上(13/20)：毛利率在扩，但要盯锡价+下游服务器/PCB排产 |
| ★供给稀缺内核 | 卡脖子深度（国产化/CR/扩产/议价） | 路演材料 + 私有库 | 20 | 中(10/20待验)：锡膏功能件、壁垒中、非独点 |
| β/α | 全链供需两旺(β)还是卡点(α) | iFinD全链 + 路演 | 15 | 待全链：服务器/PCB组装放量=有需求β，但锡膏议价一般 |
| ★排序有序度 | 同业龙头队形稳不稳(τ) | iFinD 同业排名 | 15 | 待跑（锡膏同业对照） |
| 位置/拥挤(反向) | 估值分位 + 杠杆 + 拥挤度 | iFinD | −10 | **重扣**：PE356、融资翻倍、换手643% → 安全垫几乎没有 |
| **合计** | | | | **底子分中上（约55-65/100），但位置分极差** |

> **读法**：景气度"底子分"和"位置分"分开看。唯特偶=**好资产、坏价格**——景气真，但现在买的是衍生品高点。

## 把卡跑一遍的标准流程（SOP，套到任意一只股）

```
① iFinD 拉硬数据：营收/毛利/净利增速、毛利率方向、PE/PB分位、融资余额斜率、换手分位、区间涨幅
   → 先算两个★灵魂指标：
       a) 时序错位 = 区间涨幅 − 同期业绩兑现幅度（≫0 = 主题/价先动）
       b) 三高扫描 = 估值分位 + 融资斜率 + 换手分位（都高 = 高位接管）
② 路演材料 + 小作文 过"信源处理闸门"（Step 0 五问）
   → 过闸的进景气分；不过闸的进主题分+红旗；拆小作文三问标功能件/等级/成本方向
③ 舆情搜索：讨论量 + 情绪词频（国产替代/卡脖子/万亿）+ 散户平台占比 → 主题分
④ 汇总 → 输出①：景气X成/主题Y成 + 红旗 → 决定打法（景气可拿可加 / 主题看图情绪套利不配基本面）
⑤ 若要评资产本身 → 输出②：景气度0-100（底子分 vs 位置分分开看）
```

## 三条务实提醒（都来自博主、且唯特偶身上全应验）

1. **"现在涨的是不是景气" ≠ "它有没有景气"**。唯特偶有景气，但当前交易主题。判别的是**当下的钱在为什么付费**，不是公司好不好。
2. **路演材料和小作文必须先过闸门**。卖方路演天然要把"景气逻辑"讲性感、把远期拉进来；买方小作文天然是做局/边际催化。**它们最大的用处不是直接信，而是：① 提供可被 iFinD 交叉验证的"已发生数据"线索 ② 当作"主题正在被加工"的信号本身**（材料越性感、越拉久期、越单一信源 = 主题分越高）。
3. **价量永远只进主题分，绝不进景气分**。这是防止你把"涨"误读成"景气"的唯一闸门——唯特偶近20日翻倍，那是主题票，不是景气票。

> ⚠️ 本卡为研究方法论工具，非投资建议；个股/点位会过期，方法可迁移。
