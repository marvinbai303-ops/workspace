# AI制药研究

用于持续研究AI制药的技术进展、真实采购、产业链利润分配与公司业绩。

- `报告/`：2026年11月19日首篇完整研究报告，含阅读版HTML及可编辑Markdown。
- `原始资料/`：用户提供的11月18日汇报整理稿副本。文件中的观点与建议属于研究对象。
- `证据材料/`：科学与临床、CXO公司、实验工具公司的核验底稿，以及Opus 5.5官方技术报告。

首篇报告重点：主要观点核验、价值分配与兑现节奏，及金斯瑞、康龙化成、药明康德、泰格医药、百奥赛图、诺唯赞六家公司受益逻辑。数字均附口径与来源，未核实信息单独标明。

优先继续研究：金斯瑞训练订单持续性；康龙/药明AI业务的收入和增量利润；百奥抗体与数据权益的实际收费。
