## 0. 速览：这条链的景气长在哪

- **一句话逻辑**：AI算力互联，确定性 = **上游供给稀缺性** + **路线无关的物理刚需**。景气最强的**不是**模块组装（利润大但被卡），而是①上游卡脖子环节（光源/衬底）②路线无关的"卖铲人"节点（FAU/MPO）。
- **β/α 定性**：**光模块本身没有β**——一二级仍被海外光源/衬底卡脖子，季报做出来就把经营动作做完了，没有供需两旺的全行业β，只能涨α（卡点定价）。真β要去算力链别处找（PCB/CCL，见`07`）。
- **景气 vs 舆情**：景气驱动为主，但**高位时机构行为学主导**——CPO是"涨=抱团，跌=踩踏"的三高品种（高拥挤+高估值+高杠杆，V110）。
- **核心心法**：**"毛确定性，不读路线"**——别赌CPO/可插拔/NPU谁赢（路线β风险，压错腰斩），去压三条路线都要用的物理刚需节点。

## 1. 产业拓扑骨架（拆链到颗粒度）

```
─────────        ──────────       ───────        ────────────       ───────        ────────        ──────────
MP磷化铟(InP) →   EML/CW/VCSEL →   FAU光纤阵列 →   旭创/新易盛/东山 →  MPO多芯连接器 → 光棒→光纤 →     交换机
SOI(硅光)         (光源是当前       (路线无关        天孚/华工          (路线无关        长飞/亨通/康宁    OCS全光交换
```

**关键认知（V1）**：图上节点分两类——**跟"数量/算力规模"挂钩**的（FAU、MPO、光纤）=路线无关、可同时压所有路线；**跟"路线选择"挂钩**的（具体哪种模块）=你最容易被打脸的地方。**前者是作战区，后者尽量别碰。**

```

─────────         ─────────────────           ──────────────         ──────────────
光棒自给率     →    EML光源 + MP磷化铟衬底   →    SOI衬底(硅光路径)   →    VCSEL/深化镓衬底
```

**找"下一个卡脖子"的三句话方法（V25，可直接复用到任意链）：**
1. 在产业趋势/技术路径上，它**是不是下一个卡脖子环节**？
2. 这个卡点**我们有没有真正的供给能力**（不是吹"能做"，是真能批量高良率做）？
3. 这个突破**最终谁来买单**（终端用户是谁、买不买得起）？

## 4. "找景气最强环节"的实操：个股动态排序（目标2的样本）

- **排序不是固定的**：早期"易中天(旭创/中际/天孚)" → 考虑上游供给稀缺性后调成 **圆(旭创)中(中际)东(东山)易(新易盛)天(天孚)** → 把源杰拉进前排变 **源中东易天**（因为26-28三年都紧的是光源）。
- **组合智慧"圆中东易天"（V10）**：不押宝、三点互保对冲——
  - CPU路线走不通 → 东山涨/天孚跌，稀缺性让旭创涨 → **旭创+东山对冲掉天孚**；
  - CPU进展快 → 用旭创CW光源、天孚CPO封装 **对冲东山稀缺性下降**。
- **大光出题、小光答题（V16）**：大光=确定**叙事**(不是确定景气)；小光(硅光/光源后排)=期权/波动率交易，"搓一把就跑，交了卷别裱墙上"。
- **二线抢龙三看爆发性（V44）**：标准=站在800G看1.6T；东山能否"拜万"(逼近新易盛估值中枢)取决于两拍——①CPO渗透不快②800G→1.6T能同时拿出EML+CW。

## 6. 叙事辅助：可迁移的"判断机制"（第六节是叙事，前五节是网格）

1. **"毛确定性，不读路线"**——找路线无关的卖铲人(FAU/MPO)，毛的是物理规律不是人的判断；连博通/台积电/COHR都两边下注，散户凭什么赌单一路线。
2. **"光模块没有β，只能涨α"**——确定性来自上游供给稀缺性；β要去供给能跟上的环节(PCB/CCL)找。
3. **"尽精微用错地方"**——光纤是拓扑极短的低频品种，别拿高频信息天天盘（"绣花把脑子绣坏了"）；第一性三点(供给稀缺/供给结构/需求长久期)不连在一起看，随便来条信息都能打击单点。
4. **"不梭哈才是高级智慧"**——大行业(1.6T仅组装就千亿)不争咸甜豆浆，用组合三点互保替代赌单点。
5. **下一个卡脖子三句话**（§3）——是不是卡点 / 有没有真供给 / 谁来买单。
6. **高位高估值光票=衍生品**（源杰/长飞/腾景，V65/68/69）——买方"围绕网格找壮胆理由"加仓；估值锚建在27年再做"逻辑体操"压P；向下爆炸(找不到新边际时从衍生品降格回股票，业绩还涨股价却跌)。
