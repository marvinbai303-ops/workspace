## 2. 共同主线与7月底以来的变化

来源：S2第1-3页；T4第1-2、14页。

1. **研究对象升级。** 不能把“CXO明年有没有机会”当作孤立子行业问题，应把创新药、BD、海外商业化、研发投入、临床推进、CMC、生产外包放在同一条链上。
2. **主开关是价值发现能否转为盈利兑现。** 若BD仅体现中国资产被全球认可，创新药仍是核心，CXO只是滞后修复；若资金和项目开始传导至临床、生产、商业化及全球市场份额，才可能出现“创新药+CXO+商业化”共同受益。
3. **材料描述的共识不是医药全面牛市或全面复苏。** 中国创新药全球竞争力、License-out、平台合作和全球研发认可被视为系统趋势；CXO最差阶段大概率过去，但恢复速度、利润兑现和环节分化仍有争议。
4. **BD总金额的边际催化下降。** 市场由关注“大单金额”，转为关注首付款质量、资产阶段、靶点差异化、合作方、项目优先级、临床推进、里程碑、商业化收入，以及对CXO订单的实际外溢。
5. **从板块普遍估值修复转向公司分层。** 平台型创新药、有产品收入的公司、订单和利润率可验证的CXO龙头获得更高认可；纯事件、纯BD和概念型资产被提高兑现要求。
6. **7月末：** 争论BD是否短期情绪、CXO回暖是否低基数，核心是“最差是否过去”。
7. **8月中旬：** 中报、调研和订单证据增多，材料认为创新药全球化不是孤立事件、CXO恢复也不只是口头预期，讨论转向改善的持续性与产业链扩散。
8. **8月下旬：** 重点转为订单如何进入收入、利润率、EPS和现金流，产品销售如何接力BD，创新药主线能否扩展至CXO。
9. **风险重心更内生化。** T4认为8月没有看到BD塌陷或地缘系统性阻断，新增约束更多来自国内支付端、老品种压力、订单交付时滞、汇率、资本开支和新业务爬坡。
10. **预期差不只是景气方向。** 改善斜率必须足以覆盖上涨、估值修复和仓位回补后更高的市场要求。

## 3. S2：中期战略框架完整记录

### 3.1 多空分歧与真正争论的问题

来源：S2第2页。

- **多头：** 中国医药全球化进入第二阶段：全球认可资产之后，临床推进、里程碑、海外销售和外包需求开始接力。平台型创新药继续受益，CXO由订单修复走向EPS驱动，新分子和复杂工艺可能放大利润。
- **空头：** 不否认创新药出海，但反对把BD线性外推。大量交易仍是早期资产，后续里程碑、商业化和推广不确定；创新药估值要求已高，CXO从订单到利润也可能不顺。
- **关键界限：** 创新药强，不自动意味着CXO同步进入中期景气。
- **三个争论核心：** 中国BD定价是否透支；景气能否向CXO和外包链传导；全球化定价锚能否从事件转向盈利兑现。

### 3.2 四组决定性变量

来源：S2第3页。

| 变量组 | 完整关注点 | 对判断的作用 |
|---|---|---|
| 授权后的兑现质量 | 里程碑是否持续付款；临床与注册是否按期推进；合作方是否提高中国资产全球管线优先级；海外商业化是否产生真实收入 | 判断BD是否从价值发现进入兑现，首付款本身不再是最关键变量 |
| CXO经营链条 | 新签订单、book-to-bill是否连续改善；订单能否转收入；利润率与经营现金流是否同步修复 | 区分低位修复与景气重估 |
| BD/融资后的资金用途 | 偿债、维持运营、修复资产负债表，还是投入临床、CMC、生产、新项目和外包 | 决定向CXO传导的力度与速度 |
| 国内产品收入与海外商业化 | 能否形成“BD+产品收入”双轮驱动，海外销售能力能否建立 | 决定估值上限；没有销售接力则回到更保守估值 |

### 3.3 三层验证信号

来源：S2第4页。该部分题为“验证信号与阈值”，实际主要列方向性信号，没有统一数字阈值。

- **创新药：** 里程碑和海外销售持续兑现；海外临床推进；合作方公开提高项目优先级；平台创新药收入占比提升，而非只依赖首付款。
- **CXO：** 新签订单及book-to-bill继续改善；产能利用率、利润率、经营现金流同步上修；新分子和商业化项目占比增加。
- **统一主线：** 创新药和CXO相对收益重新收敛；事件利好同时带动两端；ETF和主动资金同时提高两类资产配置。原文强调新闻必须转化为产业传导与盈利兑现。

### 3.6 S2最终配置表述

来源：S2第8页。

- 医药主仓位继续以创新药为核心，不机械采用创新药与CXO各一半。
- 对CXO保持中高关注度，加仓依据是订单、利润率、现金流及BD里程碑向外包的传导。
- 优先考虑同时受益于全球化能力认可与后续兑现强化的平台资产和龙头CXO。
- A显著抬升时扩展为系统性产业链配置；C或D抬升时回到兑现质量和现金流确定性。

## 4. T4：未来4-6周的问题分层

### 4.1 短期叙事与窗口限制

来源：T4第1-2、4-5页。

- 本窗口交易的是“复苏兑现质量”的概率变化：BD、订单、融资能否转化为里程碑、临床、产品销售、收入指引、利润率与中线资金配置。
- 四个问题：订单是未来EPS储备还是阶段性脉冲；BD是平台与现金流闭环还是一次性首付款；新分子/AI是订单中枢抬升还是短单主题；低配回补能否成为中线配置。
- 不会在窗口内完整看到Q3财报，只能先看中报后业绩会、订单结构、库存/在产品、会议摘要和数据预期、政策执行反馈、月度融资/BD、价格对新闻的反应。
- 原文以单一主轴列三种状态：兑现超预期、基本面强但硬证据不足、兑现低于预期；再单列地缘/临床/宏观造成的非连续冲击。资金风险偏好会放大各状态。
- 硬证据不足使中间情景权重偏高；8月中报强于7月底，又使上行情景保持较高权重。

### 4.4 C层：长期背景的四项约束

来源：T4第4页。

1. 中国能否从全球BD资产供给方成为全球商业化平台，决定估值天花板；本窗口仅看海外III期、FDA节点和产品收入代理信号。
2. AI是否提高临床成功率，需要多年临床结果；短期只看条款和合作期限。
3. 新分子产能与价格竞争，产能释放、利用率爬坡、注册核查需2-8个季度；短期看排产、PPQ/BLA和毛利口径。
4. 医保支付制度长期支持真创新的力度；短期看基药执行、商保目录和医保谈判预期。

### 5.2 情景1：兑现升级，EPS接棒BD

来源：T4第5-7页。

**假设与问题状态：** 全球研发和中国BD仍处高位，9月不快速降温；订单延迟属于交付时滞而非需求信用风险；产品型创新药以销售和里程碑接住BD。A1订单兑现得到验证、A2执行质量强化、A3资金由交易向主动中线扩展、B2国内商业化部分验证、B4地缘权重下降。

**演化链：** 融资/BD总量保持高位，或总额波动但首付款和执行质量不弱 → 会议摘要/数据积极 → 临床启动、里程碑与MNC优先级延续 → 平台产品收入及创新药占比提高 → CXO管理层维持或上修订单/收入/利润率 → 剪刀差被解释为正常交付 → 盈利预测上修快于估值扩张 → 主动资金接替ETF/量化 → 龙头从周期修复转向成长定价，二线跟随但分化。

**原文证据：** 凯莱英新签/在手订单及新兴业务增长，药明康德在手订单与全年指引上修，Charles River订单与book-to-bill，内部CXO真实复苏概率升至80%，调研中的“超跌修复+产业趋势”。具体数值及出处见第8节。

**验证要求：** 龙头订单同比20%-30%+；新分子/商业化项目更快为超预期；现金流改善、经调整利润率稳定或上修、汇损不扩大；已签BD出现启动/付款/优先级确认；平台创新药收入占比上升且老品种压力不扩散；利好后放量上涨或缩量回调，资金承接良好。

**概率迁移：** 若9月融资同比保持30%+、龙头持续正面订单/指引、WCLC/ESMO预期积极，原文允许35%升至45%-50%；若“符合预期但不涨”，退向情景2。材料未给这一调整下其余三项概率的完整重分配。

**多空各自的修正条件：** 多头在订单低于20%、转收入弱、汇率/Capex侵蚀利润、销售弱或会议数据平淡时下修；空头在订单和利润率同时上修、里程碑连续兑现、二线订单质量也改善、股价对利空钝化而对利好敏感时修正。

**情景切换：** 基本面不差但缺催化→2；订单斜率/销售/利润关键项明显低于预期→3；地缘清单、重大临床失败、宏观冲击→4。

**产业链与配置：**

- 上游：模式动物、安评、试剂耗材、药物发现CRO较早受益，价格和利用率改善。
- 中游：CXO龙头、新分子CDMO、CRDMO平台受益，原文预期利润率弹性可强于收入。
- 下游：平台创新药、有产品销售的Biotech受益，纯BD涨幅受限。
- 优先：药明系/一体化CRDMO、新分子CDMO、多肽/ADC/XDC能力强、产品+BD双轮平台。
- 次级机会：临床前CRO、模式动物、科研上游、海外执行能力强的Biotech。
- 承压或回避：无订单披露、无产品收入、只靠BD总额的早期Biotech；高估值纯AI概念；低毛利传统小分子产能；解释不清现金流与利润率的企业。

### 5.3 情景2：高位震荡，龙头阿尔法分化

来源：T4第7-9页。

**假设与问题状态：** 复苏未被证伪，但不应线性外推H1高增长；市场愿意持有确定性龙头，不给全板块无差别溢价。A1订单真实但利润待Q3、A2执行部分验证但大单催化下降、A3低配回补存在但交易波动增加、B2支付政策继续造成分化、B3新分子强而AI偏主题。

**演化链：** 中报利好兑现 → 9月缺完整季度数据 → BD只奖励首付款、合作方、阶段、靶点差异化 → CXO龙头凭订单能见度相对抗跌，二三线因涨幅和兑现不确定分化 → ETF/量化普涨转主动精选 → 创新药转向销售、海外数据、平台能力 → 指数震荡、个股选择胜于板块敞口。

**原文证据：** 8月25日内部结论主张围绕兑现再分层；医疗服务景气度下降、医药生物一级景气度改善，说明并非全链条同步；ETF转弱、主动偏股资金当周转正，提示资金换手。数值见第8节。

**验证要求：** 龙头跌幅小于二三线、利好时先修复；大额BD不再全面带涨，只奖励高首付/后期/差异化；主动净流入而ETF波动；成交保持但不失控，缩量阴跌为转弱；管理层维持目标但少大幅上修。

**概率迁移与多空修正：** 无强新增证据、也无证伪时保持主导；多头应降低二三线和纯主题敞口，转订单与现金流可验证公司；空头在龙头估值合理、回调承接强时，应承认是分化而非简单行业见顶。

**情景切换：** 连续订单/里程碑/数据超预期，带动EPS上修→1；订单和销售低于预期、好消息不涨且二线补跌→3；外部风险整体压缩估值→4。

**产业链与配置：**

- 上游早研相对强，但也要有业绩；中游一体化、披露透明胜出，小而散承压；下游平台优于纯BD，产品线决定估值差。
- 优先：订单透明、利润率稳定、估值合理的CXO龙头。
- 次级机会：平台创新药、有产品放量和海外数据催化的Biotech。
- 承压或回避：涨幅大、缺业绩的上游和AI主题；无现金流、毛利支撑，却把H1订单线性外推到2027-2028的公司。

### 5.4 情景3：兑现折扣，成长定价回撤

来源：T4第9-10页。

**假设与问题状态：** 高增可能含基数效应和集中交易，订单斜率下降；首付款和里程碑接不住产品波动；汇率、Capex、低价历史订单、客户递延压制利润。A1被弱化或证伪、A2项目和付款慢、A3回补成为短线轮动并撤离、B2支付/准入压制销售、B3远期新分子/AI故事暂时退居次要。

**演化链：** 融资/BD增速回落或大单质量低 → 怀疑H1低基数和交易集中 → 管理层提示递延、只维持收入而不给利润指引、汇率/Capex拖累 → 新品受续约、竞品集采、准入压制 → 纯BD缺里程碑证明 → 盈利预测由上修转观望/下修 → 成长PEG转周期PE → ETF/量化离场，主动仅保留龙头 → 指数回调、分化加大。

**原文证据：** 早期BD占比高、首付款占比低；内部对BD可持续盈利的质疑加强，对国内销售接力的信心下降；融资可能用于偿债、运营或自建团队而非外包。

**验证要求：** 龙头新签同比低于20%或环比明显回落且解释不清；收入增长但经调整利润率下降、现金流不改善；大额BD没有启动/付款或项目被降低优先级；创新药产品收入环比放缓、老品种压力扩散；利好后冲高回落或不涨。

**概率迁移：** 融资同比低于20%、CXO订单口径弱于20%-25%、或销售继续受支付扰动，原文允许20%升至30%-35%；任一龙头上修全年指引则该情景降权。其余情景的完整重分配未给出。

**多空修正与切换：** 多头下调线性订单外推与二线估值，转现金流、利润率和产品销售；空头若看到龙头订单/利润/现金流仍强，不应把二线回调等同全行业反转。负面局限个别公司、龙头稳→2；后续订单/里程碑快速修复→1；负面叠加地缘/临床失败→4。

**产业链与配置：**

- 上游交付周期短的公司先显压力，模式动物/安评对价格回落敏感。
- 中游二三线、高Capex、低套保、低毛利历史订单、披露不透明者承压，龙头相对抗跌。
- 下游纯BD估值压缩最大，有产品及海外商业化能力者相对稳定。
- 优先：防御性高股息、现金流稳定药企、低估值龙头；其次为产品销售确定的平台药企。
- 回避：纯BD、纯AI、没有收入/利润锚的高弹性标的。

### 5.5 情景4：尾部打断，外部风险重定价

来源：T4第10-12页。

**假设与问题状态：** 单一非连续事件即可从复苏兑现切换到尾部防御。A1订单数字暂居次要；A2合作条款和优先级被重审；A3交易资金撤离、主动等澄清；B4地缘升至A层；C层长期全球份额被折价。

**演化链：** 美国名单/法案/实体限制传闻或落地，核心中国BD资产海外临床失败，或全球风险偏好急降 → 先看海外收入持续性和美国新增订单可得性 → 高海外/美国收入、缺海外产能者折价 → MNC双供应链审计、递延、重谈 → 首付款及交易条件受压 → 盈利预测下调前估值先降 → 资金转低估值、内需和产品收入确定方向。

**原文证据：** 内部材料把2026Q4-2027H1列为细则、名单、供应链策略节点；提到美国《生物安全法案》、1260H清单、OMB名单；市场阶段性脱敏可能使突发波动更大。本文仅记录提及，不核定政策状态。

**风险阈值：** 名单覆盖头部CXO/Biotech，或限制从政府合同外溢商业客户；美国客户新签占比下降、要求双供应链/技术转移；BD首付下降、美国权益排除、重谈；高关注III期未达主要终点或安全性信号；龙头放量破位、港股沽空/卖压上升。

**概率迁移：** 无负面保持低概率；名单或临床失败发生时，可由7%直接跳升至20%以上，无须经过情景2的缓慢迁移。未给完整的其他概率重分配。

**多空修正与切换：** 原文主张多头降低已修复估值且海外敞口高的资产，等待订单、客户、合规澄清；若公司证实订单不变、客户履约、限制范围窄，空头需修正，风险退回背景。范围有限但不普涨→2；未系统阻断但斜率下修→3；风险落空且基本面超预期→1。

**产业链与配置：**

- 国内客户为主的早研相对抗跌，但仍可能受融资风险偏好二次冲击。
- 美国客户/海外收入占比高的CXO最敏感；新加坡、欧洲等海外产能布局清晰者相对占优。
- 国内产品销售和非美BD路径相对稳；早期出海Biotech折价扩大。
- 优先：内需产品稳定、强现金流、高股息或防御性药企；其次为非美市场与海外产能布局清晰的CXO。
- 承压或回避：美国客户集中、早期BD依赖高、全球化高成长已充分反映在估值而缺少地缘缓冲的资产。

## 9. T4的八项投委会决策结论

来源：T4第13-14页，按原文顺序完整保留。

1. 未来4-6周研究“复苏足不足以兑现EPS和现金流”，不再把“有没有复苏”作为主问题；这是相对7月底最大变化。

3. 优先订单可核验、利润率可解释、现金流能跟上的龙头；回避只靠BD总金额或AI主题、无法形成在手订单的标的。
4. 最强短期边际信号是已签BD的临床推进、里程碑到账、CXO上修指引、产品收入接力，而不是单纯新增大额BD。

## 11. 口径差异与待讨论事项

**本节是本次阅读形成的核对备注，不是冒充投委会新增结论。这里只保留需要厘清的地方，后续讨论再展开。**

1. **战略与战术不能直接合并。** S2研究未来1-3年、以创新药优先为基准；T4研究4-6周、核心仓位同时放CXO龙头和平台创新药。期限和情景定义不同，不能把25%与35%直接说成“盈利重估概率上调10个百分点”，也不能默认两份已经达成同一仓位结论。
2. **从订单复苏到盈利重估尚有条件。** 材料偏向确认复苏，但没有完成连续订单、利润率、现金流和商业化收入的统一验证。标题提出的是待验证命题，不是已经坐实的行业切换。
3. **表观资金证据与医药专属资金证据需分开。** A股情绪、主动偏股公募总净流入，只能支持市场背景；要确认医药得到中线接力，仍需行业持仓、净流入或其他明确的医药维度证据。
4. **时间窗与财务兑现不能混淆。** T4自己承认看不到完整Q3报表，很多传导需数个季度。因此4-6周内可以更新预期，但不能仅以没有销售或利润落地判定长期链条失败；反过来，也不能只凭短期新闻宣布完成盈利验证。
5. **概率和阈值尚缺统一计算依据。** 概率是主观权重；T4的局部概率迁移没有给完整再分配。订单20%等阈值没有按公司基数、币种、业务、可取消性、疫情/大订单剔除等条件标准化，不能机械套用。
6. **BD数字有统计口径问题待核。** 中国授权与全球BD、总额与首付款、范围与中位数、签约与到账均应分别处理。未来讨论实际金额前，应回到原始交易清单或公司披露。
7. **订单到收入的时滞需按业务区分。** 原文既有1-4个季度，也有12-24个月；不能视为单一结论。不同CRO、CDMO、新分子和商业化项目的口径应分别检查。
8. **Capex、利润率和现金流的表达需要拆清。** 原文多次写“Capex吞噬利润”，后续应分别看现金支出、折旧、产能利用率及新业务爬坡费用，避免把现金流压力直接当成同期利润费用。
