# Part A · 判断现在是"交易景气"还是"交易主题"

## A0. 为什么这是生死线（不是学术分类）

他反复讲的"复合收割"就出在这：**你以为自己在投景气，实际上投的是主题。**
- 量化同时用基本面因子（景气）和价量因子（主题），在两者间来回切：你信了景气追进光，它砸你三天把你割下去；你转去做主题，它又不动了；回头光又新高。**筹码和钱都丢。**
- 更深一层（V89）：你在一个主题循环里抠细节、搓交易，等**产融视角切到下一个景气循环**时，你"拿上一个主题估值的钥匙，斩不了下一个景气循环的锁"——**结构性踏空**。
- 所以判别景气/主题**不是为了贴标签，是为了决定"用哪套打法、能不能拿、怎么拿"**。判错=用错工具=必被割。

## A1. 两套模式的本质区别：先看"谁在交易"（负债端）

| | 景气模式（产融视角） | 主题模式（舆情视角） |
|---|---|---|
| 谁在主导 | 产业层(喂数据) + 金融层(编景气估值范式) | 庄家层(改信源/做图/启舆情) + 大众层(老中小灯的欲望) |
| 驱动力 | **数据**（结构化景气数据驱动估值） | **叙事**（在数据网格的空白处用故事填充） |
| 顺序 | **先有数据/逻辑，后有估值** | **先有图，后有逻辑**（买方先把图做起来，你才被引来看） |
| 传播性 | 差（认知壁垒高、品种少、必须讲数据） | 好（认知门槛低、能蹭情绪、易蛊惑） |
| 可证伪性 | 高（数据能验、网格能拆） | 低（特意做成短期不可证伪） |

**一句话抓手**：**景气是"数据→估值"，主题是"图→逻辑"。** 判别的核心动作，就是去看这个品种当前的上涨，是**被新的景气数据推的**，还是**被一个传播性极好的故事梗推的**。

## A2. 七个判别维度（拿到任何品种，逐条打分）

1. **先有图还是先有数据？**（最锋利）主题品种是"买方先把图做起来、把信源改好、再让KOL把你引来看"——逻辑出现在图之后。景气品种是数据先变、估值后动。→ *你是看到走势才去找逻辑，还是数据先变了？*
2. **认知门槛多高？** "四个人就能看懂的故事 + 能蹭民族情绪/国产替代"≈主题；"必须讲网格、讲数据、品种少、难传播"≈景气。→ *故事是不是一看就懂、一看就想冲？是的话警惕。*
3. **估值周期能不能被网格分段解释？**（V89 的核心检验）景气品种的估值周期（如光模块3→15→7→20倍）能清清楚楚分成"**景气爆发段 / 预期博弈段 / 数据验证段**"，每一段都对得上一个产业事件。主题品种"**连分段都分不明白**"——语料突然涌上来、量化怼一下又上去，你说不清哪段是什么。→ *你能不能把它过去一年的涨跌分成可解释的段落？分不出来=主题嫌疑。*
4. **是供需供振，还是单独供给/现行外延？** 景气要"需求拉着供给、紧缺能顺价传导"。主题常见两种造假：① 把**特定早期周期**的真实景气**线性外延**成长期趋势（"小孩一岁吃辅食≠八岁还吃辅食"）；② 把两个不同概念**混淆**（如海外大厂"以租代购摊销资本开支"的租赁价 ≠ 国内中小企业卖充式租赁需求）。→ *这个需求是结构性持续的，还是一次性/早期被外延的？*
5. **有没有"数据PS"痕迹？**（V88，升级版主题最毒）产融资本进场后，篡改的**不再是叙事、而是数据本身**：数据污点扣掉、亮点拔亮、甚至控制上市公司业绩发布节奏；海外空白区先编好、反向影响回国内=**A货高仿**，长得跟正常产融语料一模一样。→ *这个"硬数据"是不是只有单一来源、且来源能被操纵？*
6. **景气三拍凑齐几个网格脸？**（V50）景气三拍 = 26订单 + 27景气延伸 + 28宏大叙事；**上游2+下游2 = 四个网格脸刚好凑齐时，往往已是舆情主导的高位**。→ *四个脸是刚凑齐（高位预警），还是还缺脸（前期）？*
7. **海外映射在哪一层？**（V128）结构性景气(LITE/COHR→抱团层) / 总量性景气(博通Marvell→交易层) / 情绪(甲骨文→观察层)。越靠后越偏主题。

> **输出**：七条过一遍，给个比例——"**景气几成、舆情几成**"（如 PCB 当时=景气3-4成、舆情6-7成）。这就是参与方式的依据。

## A3. 三把标尺（用他验证过的案例校准你的判别）

| 标尺 | 性质 | 特征（拿来对照新品种） |
|---|---|---|
| **光模块** | 纯景气 | 估值周期能完整分段解释；上游供给稀缺是硬内核；个股排序稳定有序；先有数据后有估值 |
| **算力租赁** | 纯主题 | 故事梗"海外缺卡→国内租赁爆发"传播极广；卖方把早期景气外延成长期+混淆大厂/中小概念；买方联合商人公司虚造报表（号称去新加坡买卡其实买不着）；KOL情绪周期套利、炒二波三波；先有图后有逻辑 |
| **自主科技股** | 数据PS升级版主题 | 海外"仨景气叙事带一主题"、自主科技"一景气叙事带仨主题"→**海外坑你一次、自主科技坑你三次**；产融资本+量化联手，数据PS+技术周期美化，A货高仿到量化都识别成真→量化怼进来磨损你 |

**判别一个新品种 = 看它更像这三把尺子里的哪一把。**

## A4. 实操判别流程（可固化成每个品种的起手动作）

```
拿到品种
  → ① 它现在涨，是数据先变还是图先动？（先有图=主题嫌疑）
  → ② 故事是不是一看就懂、蹭不蹭民族情绪？
  → ③ 过去一年估值周期能不能分段解释？（分不出=主题）
  → ④ 需求是供需供振，还是早期外延/概念混淆？
  → ⑤ 硬数据有没有PS痕迹/单一可操纵来源？
  → ⑥ 四个网格脸凑齐没？（凑齐≈高位）
  → 给比例：景气X成 / 舆情Y成
  → 决定打法：
       景气主导 → 用景气打法（堆β / 做α弹性 / 抓供给稀缺内核），可拿、可加
       主题主导 → 用主题打法（看图、情绪周期套利、别配基本面、切记不炒二波），快进快出
```

## A5. 对你的特别警告（你是产业/机构出身，这条最要命）

他在 V89/V88 里**反复点名"产业出身、理工科、小镇做题家"这类人最容易在主题上栽**，原因恰恰是你的强项：
- **你越用基本面去验，越上当**。因为主题升级成"数据PS"后，语料长得和正常产融网格一模一样，你拿放大镜抠细节，抠出来的全是被设计好的链路。"**情绪套利本身是看图的视角，你越配上基本面越容易上当，因为你做的交易不纯。**"
- **量化专门在产业细节（OCS/FAU/光芯片这些网格空白处）给你画靶子**："你键往左骗他往左画，你键往右骗他往右画；割不动散户了，就开始割专家。"
- **抠细节�on的边际收益其实很低**：他原话——"时隔半天，不如19年把宁德从头拿到尾。抓产业主干、放细节、集中仓位在核心个股，效果更好。"
- **现在有AI更狠**：能分析你过去在什么范式上容易上头，专门给你生成你"想听"的语料。

→ **你该做的**：判别景气/主题这一步，**优先用"先有图还是先有数据""能不能分段解释"这种结构性问题**，而不是一头扎进细节去"验真"。结构上一拍，比细节上抠半天可靠。

# Part B · 景气诊断：找"景气最强的那一格" + 判断它强到什么程度

> 这是你目标2的正题。景气诊断**不是看涨跌**，是看"**产业网格的供需结构 + 个股队形**"。下面是一套可套到任意一条链的诊断仪表盘和流程。

## B1. 景气诊断仪表盘（7 个读数）

| # | 读数 | 怎么看 | 强信号 / 弱信号 |
|---|---|---|---|
| 1 | **个股排序有序度** ★最锋利 | 看这条链龙一龙二龙三是否**稳定**（只调内部、不动大结构），还是**像电风扇**（谁拿单谁涨一段、轮流上桌） | 稳定有序=景气强、有资格估值扩张 / 排序乱换=需求飘供给大、没持续性 |
| 2 | **供需状态三档** | 供不应求 / **供需两旺(最强)** / 供大于求 | 两旺=最强 / 供大于求=景气见底 |
| 3 | **β 还是 α** | β=供需两旺可堆仓（需横跨海外+国产双循环）；α=有卡点可定价做弹性 | 真β=景气最强可堆仓 / 只能涨α=景气有但被卡、做弹性 |
| 4 | **估值周期段位** | 景气爆发段(0→1每节点都涨) / 预期博弈段(冲太猛炒完未来→阴跌绣花) / 数据验证段(新指引兑现再怼) | 验证段=可加 / 博弈段=震荡防守 / 爆发段=最舒服但最短 |
| 5 | **供给稀缺内核** | 景气最强的环节往往是**上游供给稀缺**（光源/衬底），不是利润最大的组装 | 卡脖子越深、扩产越慢=景气越能持续 |
| 6 | **能否顺价/供需供振** | 紧缺要能**顺价传导**到下游才是可持续景气，不能只是单独供给紧 | 能顺价=可持续 / 单独供给紧但顺不动=易证伪 |
| 7 | **网格脸凑齐几个** | 上游2+下游2 | 还缺脸=前期 / 刚凑齐=接近高位 |

## B2. 把排序有序度讲透（B1 的第1读数，最该单独学会）

这是他最独到、对你选股最直接的一招（V137/V44）：**个股排序的"有序度"本身就是景气强弱的诊断仪。**

- **机制**：景气 = 中期供需状态；叙事 = 给每只个股派角色（男一号/男二号/补涨）。当**供需健康**时，谁是龙头、谁是龙二是**有产业逻辑、稳定**的（光的"圆中东易天"，只在内部微调）。当**供需不健康（需求飘、供给一拥而上）**时，排序就**没有锚**——谁传出拿到订单谁就猛涨一段，"三花→卧龙→长盈轮流上桌、快赶上电风扇"。
- **怎么用来诊断**：
  - 看一条链的龙一龙二龙三**这三个月稳不稳**。稳=景气有资格估值扩张；天天换=景气是"轮流提估值、谁被踹下桌谁杀估值"的恶心形态，**别碰持续性**。
  - 排序**会随景气演进有序迁移**才正常（光：易中天→圆中东易天→源中东易天，是因为"考虑上游供给稀缺性、26-28三年都紧的是光源"才把源杰拉进前排）。**有序迁移=景气在深化；无序乱跳=景气在透支。**
- **反推选股**：你想找"景气最强的那一格"，就去找**排序稳定、且龙头位置有清晰产业理由（供给稀缺/能顺价/能足量交付）**的那条链/那个环节——而不是去追"今天涨停的那只"。

## B3. 景气诊断 SOP（套到任意一条链，输出"哪格最强、多强、在哪段"）

```
① 画网格、拆到颗粒度          → 这条链有哪些环节（拆到可买的细分品类）
② 找供给稀缺内核              → 哪个环节最卡（国产化低+扩产慢+议价强）→ 景气最强的候选格
③ 看个股排序有序度  ★         → 排序稳=景气强；电风扇=没持续性（先筛掉）
④ 定 β/α                     → 堆仓的β还是做弹性的α（决定打法和仓位）
⑤ 定估值周期段位             → 爆发/博弈/验证（决定现在加还是等）
⑥ 验顺价 + 数网格脸          → 可持续性 + 离高位多远
⑦ 叠主题判别（Part A）        → 现在景气几成舆情几成（别把主题当景气加）
  → 输出：这条链景气最强的是【某一格】，强度【β/强α/弱α】，处在【某段】，离高位【几个脸】
```

## B4. 用光模块走一遍（worked example，看 SOP 怎么落地）

| 步骤 | 光模块上的读数 |
|---|---|
| ① 网格 | 衬底(MP/SOI)→光源(EML/CW)→FAU→模块→MPO→光棒→交换机 |
| ② 供给稀缺内核 | **上游光源(EML)+MP磷化铟衬底**=当前最卡（住友+AXT 80%、缺口70%、2028才扩出来）→ **景气最强的格在上游，不在组装** |
| ③ 排序有序度 | "源中东易天"稳定、且迁移有理由（拉源杰进前排=因为光源稀缺）→ **有序=景气真强** |
| ④ β/α | 光模块**没有β**（被海外光源卡），只能涨α → 做弹性不堆仓；真β要去PCB/CCL找 |
| ⑤ 段位 | 当前在**预期博弈段**（上游涨价、下游能否顺价、定价权是否丢失的博弈） |
| ⑥ 顺价+网格脸 | 旭创顺价成功（落表单价更贵）=可持续；光纤/光源/模块/连接多个脸已凑 |
| ⑦ 主题判别 | 景气主导（估值周期可分段解释），但高位时机构行为学（三高）放大波动 |
| **输出** | **景气最强=上游光源/衬底（卡脖子内核）；性质=强α非β；段位=预期博弈；打法=做上游弹性、盯顺价与CPO渗透率、防向下爆炸** |

## 一句话收口

- **判景气/主题**：先看"图先动还是数据先动"，能不能分段解释，主题就用看图/情绪套利、别配基本面（你越验越上当）。
- **做景气诊断**：先找供给稀缺内核（最强的格在上游不在组装）→ 用个股排序有序度判景气成色 → 定β/α和周期段位 → 别把主题当景气加。
