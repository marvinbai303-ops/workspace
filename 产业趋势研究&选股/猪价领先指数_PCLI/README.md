# 猪价领先指数（PCLI）研究框架

**迁入日期：2026-10-11。研究状态：框架已形成；[2026-10-11 复算](复算说明_20261011.md)提供带缺失区间的 v0.1 重建，历史回测尚未完成可复现核验。**

本目录整理此前《寻找猪周期研究框架Papers》对话中形成的 PCLI 研究，保留[原讨论](原讨论存档.md)。本文件是整理后的工作版本。原对话里出现的“当前约 71 分”“4/4 命中”和图表，仅是当时的估计或示意，缺少可在本项目复算的逐期输入与发布日期记录，**不能当作今天的实测值或已验证胜率**。

## 1. 研究目标

PCLI 的正式研究对象是**未来生猪有效供给收缩形成的猪板块行业 β 条件**，不是猪价点位预测，也不是牧原、罗牛山等单股收益预测。原讨论中，用户的目标是识别可参与的猪板块 β，再另选有弹性的交易载体。因此研究必须分成三层：

1. **产业层：PCLI-Beta。** 判断母猪、仔猪到商品猪的供给管线是否持续收缩，且未被生产效率和出栏体重抵消。
2. **市场层：猪板块相对强度。** 用同花顺猪肉概念指数 885573.TI 相对沪深 300 的表现，判断市场是否开始交易这一预期。股价指标不进入 PCLI 本身。
3. **个股层：执行载体。** 单股成本、出栏公斤数、市值、猪业务纯度和套保影响，属于选股问题，不能拿单股股价反推产业指数是否有效。

“猪价领先指数”是沿用旧名称。若严格按功能命名，它更接近**猪板块供给领先条件指数**。

## 2. 模型演变及保留版本

| 版本                | 原讨论中的结构                                        | 当前处理                                                   |
| ----------------- | ---------------------------------------------- | ------------------------------------------------------ |
| 早期公开数据版           | 产能去化 50%＋养殖亏损压力 30%＋去化加速度 20%                  | **停用。** 猪价下跌会推高亏损项和总分，却可能同时损害当期盈利；2025 年末的讨论暴露了这一逻辑漏洞。 |
| 供给版过渡稿            | 有效能繁产能 45%＋仔猪供给 25%＋淘汰/补栏 20%＋近端供给 10%         | 作为变量设计过程保留，尚未定稿。                                       |
| **PCLI-Beta 工作版** | 母猪产能收缩 45%＋仔猪管线收缩 25%＋有效供给收缩 20%＋效率/体重反向修正 10% | **本项目主版本。** 权重来自原讨论的研究假设，尚未经过无前视回测校准。                  |

工作版的概念式为：

```text
PCLI-Beta = 0.45 × 母猪产能收缩信号
          + 0.25 × 仔猪管线收缩信号
          + 0.20 × 有效供给收缩信号
          + 0.10 × 效率/体重反向修正信号
```

四项必须先被映射到同一分值区间。最后一项的方向应定义为“**未被效率或重量抵消的程度**”：当 PSY、成活率或出栏体重上升足以抵消母猪减少时，该项应降低总分。原讨论没有给出标准化函数、缺失值规则和详细阈值；在这些规则固定前，不得计算一个貌似精确的 PCLI 点位。

**养殖亏损单列为 Stress Index。** 它用于判断去产能的持续压力，不能直接替代“有效供给已经收缩”的证据，也不应因亏损加剧而机械触发买入。

## 3. 观察指标和经济传导

| 环节     | 优先观察                    | 必须防止的误读                   |
| ------ | ----------------------- | ------------------------- |
| 远端产能   | 能繁母猪存栏及其环比、同比；淘汰与补栏     | 母猪头数下降不等于未来猪肉吨数一定下降。      |
| 仔猪管线   | 新生仔猪、仔猪供应或可核验的替代指标      | 仔猪价格同时受需求影响，不能单凭价格推断数量。   |
| 近端有效供给 | 商品肥猪出栏公斤数、屠宰量、猪肉产量、出栏均重 | 企业“总销量”常混有仔猪、种猪；头数不是猪肉吨数。 |
| 效率抵消   | PSY、成活率、平均出栏体重、规模化效率    | 生产率提高可能抵消能繁母猪去化。          |
| 压力观察   | 自繁自养利润、现金流和持续亏损时间       | 亏损是未来去化的诱因，不是当前供给已收缩的证明。  |

核心因果链是**能繁母猪 → 仔猪 → 商品肥猪公斤数 → 猪价**。每一环有生物周期和数据披露滞后，不能把同月企业销量下降直接解释成远期产能去化。

## 4. 信号状态与交易解释

原讨论暂设 PCLI 低于 55 为 OFF，55—70 为 WATCH，高于 70 为 ON。这些数值是**未校准的研究阈值**，本项目暂只将其作为原方案记录，不用于自动给出仓位。

| 产业条件 | 板块相对强度 | 研究解释                       |
| ---- | ------ | -------------------------- |
| 弱    | 弱      | 缺乏行业 β 证据。                 |
| 强    | 弱      | 产业预期可能尚未被市场接受，继续核验供给链条。    |
| 弱    | 强      | 可能是题材、流动性或其他因素，应避免误称为供给驱动。 |
| 强    | 强      | 产业与市场信号共振，再评估个股载体及赔率。      |

市场强度可从 `885573.TI / 沪深300` 的相对走势、20/60 日变化及板块对新信息的响应观察。**相对强度只负责交易确认，不得反向修改 PCLI 历史值。**

## 5. 对原讨论回测的审查结论

原讨论用中证畜牧养殖指数 930707 代替部分时期缺失的 885573.TI 历史行情，并按若干猪周期事件观察表现。这只能算**探索性事件复盘**，当前不能报告为有效的十年准确率，理由有三项：

1. 原始逐月 PCLI 输入、标准化公式和每条数据的实际发布日期未保存，无法独立复算。
2. 周期窗口和信号状态可能在看到后续行情后划分，存在样本内选择和参数拟合风险。
3. 930707 包含饲料、禽养殖等成分，与要交易的猪肉概念指数 885573.TI 并不等价。

原讨论中的历史图还把季度末数据绘在所属季度末，而部分数据在数周后才发布，存在**前视偏差**。历史测试必须以公众**实际可获得日期**入库和触发信号。旧图只能作研究过程资料，不能作为择时证据。

## 6. 2026 年 9 月销售简报如何接入

本项目已核对过部分 885573.TI 成分股的 2026 年 9 月销售简报。它们可辅助检查**近端出栏节奏和价格方向**，但不能直接给 PCLI 重新打分。尤其需要逐家公司区分商品肥猪、仔猪、种猪及内部销售，并关注出栏重量；也要等待尚未披露月报的主要猪企。单月销售头数变动只能作为有效供给模块的一个候选观测量。

## 7. 下一步交付标准

只有完成[数据和回测清单](数据与回测清单.md)中的逐期数据、发布日期、标准化规则及无前视回测，才更新“当前 PCLI”和阈值。任何数值输出都同时记录**观察月份、首次可用日期、来源链接、输入口径、版本号**。
