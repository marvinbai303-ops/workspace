# 抖音视频批量转写操作指引

> 目的：把目标博主的口述内容变成可检索、可蒸馏的文字稿，再交给 Claude 提炼"产业研究 + 投研框架"。

## 一、为什么需要你先转写（而不是我直接看）

- 抖音是登录墙 + 强反爬，自动化抓取拿不全视频列表。
- 视频核心信息是"语音"，平台不提供可提取的字幕文本轨。
- 所以最高效的分工：**你负责把语音变文字，我负责把文字变框架。**

---

## 二、推荐转写方式（任选其一，按省力程度排序）

### 方式 A：剪映「识别字幕」（最省事，零成本，适合手机/电脑）
1. 抖音 App → 进入博主主页 → 找到目标视频 → 分享 → 复制链接（或保存到本地）。
2. 打开剪映（手机或电脑版）→ 新建项目 → 导入该视频。
3. 文本 → 智能字幕 → 识别字幕（自动语音转文字）。
4. 字幕生成后：电脑版可「导出字幕（.srt/.txt）」；手机版可全选复制文案。
5. 把每条视频的文本贴进下面"三、转写稿模板"。

### 方式 B：通义听悟 / 飞书妙记（适合批量、能自动断句分段）
1. 下载视频文件（见下方"如何下载抖音视频"）。
2. 上传到通义听悟或飞书妙记 → 自动转写 → 导出文本。
3. 这两个工具会自动分段、去口水词，质量较高。

### 方式 C：本地 Whisper（适合量大、追求准确率、不想上传第三方）
1. 批量下载视频文件。
2. 用 OpenAI Whisper（或 faster-whisper / WhisperX）批量转写：
   - 示例命令（装好 whisper 后）：`whisper 视频文件.mp4 --model medium --language zh --output_format txt`
   - 量大可写个循环：把所有 mp4 放一个文件夹，循环跑。
3. 输出的 .txt 直接用。

### 如何下载抖音视频（无水印）
- 抖音 App 内：分享 → 保存本地（部分视频可直接存）。
- 或用浏览器打开视频页，复制链接到「抖音去水印解析」类小工具下载。
- 注意：仅用于个人学习研究，勿传播。

## 三、转写稿提交格式（重要 —— 按这个格式给我，我蒸馏效率最高）

每条视频用下面这个块，能填多少填多少（标题和日期能帮我判断时效性和归类）：

```
### 视频 N
- 标题/主题：
- 发布日期（大概也行）：
- 链接（可选）：
- 转写正文：
<把转写文字整段粘贴在这里>
```

> 小技巧：**一次给我 5–10 条就能开工**，不必等全部转写完。我会边收边归档进《产业网格拓扑图》骨架。

## 四、我拿到文字后会做什么

1. **过滤**：自动剔除"热点事件点评、板块涨跌点评、短期情绪"内容，只保留产业研究与方法论。
2. **归类**：按三大核心问题归档 —— ①找下一个卡脖子环节 ②卡脖子环节的供给/扩产能力 ③下游需求与跟踪方法。
3. **蒸馏框架**：提炼出博主可复用的"产业链拆解 → 卡脖子定位 → 供需研究"方法论。
4. **填图**：把具体产业案例、跟踪指标填进《产业网格拓扑图》，并标注可直接用于 A 股选股的落地动作。

---

## 五、转写质量小提醒
- 行业黑话/缩写转写常出错（如"碳化硅"可能被识别成别的），不用手动修，我能根据上下文还原，但如果你一眼看出严重错字可顺手改。
- 数字（产能、价格、增速）很关键，若转写不清，凭印象备注一下更好。
