# 07 · 产业拓扑研究方法论（提炼自博主 · 主文档）

> **这不是视频复述，是把他的"产业拓扑研究法"抽象成一台你能套到任意一条链上的引擎。**
> 三个轴：
> - **纵向**＝沿价值链建图、定颗粒度、找卡脖子、判迁移 → 回答「这条链长什么样、卡在哪、下一个卡哪」
> - **横向**＝在网格里把环节互相比、排景气、定估值范式 → 回答「哪一格景气最强、该用什么模式定价」
> - **边际变化**＝动态更新、拆信号、识拐点、防证伪 → 回答「什么变了、要不要调、调哪里」
>
> 案例（光/存/封/PCB）只作**一句话锚点**印证方法，不是主角。带 ★ 的是可直接复用的核心决策点。
> 与`04`的关系：`04`是买方科技投研的"操作系统(哲学/产融/估值观)"；`07`是其中**最操作化的"产业拓扑研究引擎"**——你日常拆链、排景气、找最强环节，主要用这一份。

## 〇、三轴怎么咬合（总图）

```
   纵向（建图）                    横向（打分排序）                 边际（动态更新）
 ───────────────              ─────────────────              ─────────────────
 ① 画拓扑图                →   ④ β/α 二分            →        ⑧ 拆小作文/拆变量
 ② 定颗粒度(拆到可买)       →   ⑤ 统一维度打分+双链验证  →     ⑨ 良性/恶性投放识拐点
 ③ 标"路线无关"节点         →   ⑥ 景气%vs舆情% 定性    →       ⑩ 排序稳定性=景气诊断
 ⑦ 找卡脖子+下一个卡脖子    →   ⑦ 估值范式三分层/映射   ──┐    ⑪ 证伪监控
        │                              │                  │            │
        └──────────────────────────────┴──────────────────┴────────────┘
                          闭环：边际变化触发重新建图/重排序
```
**一句话**：纵向把图建出来 → 横向在图上比出"哪格最强、值多少" → 边际盯住"什么变了"触发重排。**找景气最强环节 = 横向⑤⑥ + 边际⑩ 的合成。**

## 一、纵向方法论：沿价值链拆解

### 1.1 先画拓扑图（一切判断的地基）
- **规则**：没有这张图，所有判断都是在猜。从终端倒推或从上游顺推，画出「上游资源 → 材料/设备/零部件 → 模组 → 系统 → 终端」。
- **科技链是网状不是链状**：软硬交叉、全球分工、**头尾相连闭环**——下游用利润反哺上游（台积电靠苹果/高通让利支撑先进节点，又反过来"求"ASML突破）。所以不能"一个公司一个公司看"，要画网格。
- *锚点：光=衬底→光源→FAU→模块→MPO→光棒→交换机；"没这张图判断都是猜的"(V1)。*

### 1.2 定颗粒度：拆到"能对应一个可买的细分品类/公司"
- **规则**：**一个品类 ≠ 一个词**。颗粒度不够，就看不见"顶层着火、地下室漏水"的结构性短缺。
- **标准**：拆到能落到一个具体可买的细分品类/上市公司为止（不是"半导体"，是"ArF光刻胶/PSPI"；不是"光"，是"MP磷化铟衬底/SOI/EML/FAU/MPO插芯"）。
- *锚点：硅片要切成≥10个品种(12寸先进/成熟/8寸/抛光/外延/退火/SOI…)才看得清结构性短缺。*

### 1.3 给每个节点贴标签：路线无关 vs 路线相关 ★
- **决策问句**：*"这个节点的需求，是跟「数量/算力规模」走，还是跟「技术路线选择」走？"*
  - **跟数量走 = 路线无关"卖铲人"** → 作战区。可同时压所有路线，**毛的是物理规律，不是人的判断**。
  - **跟路线走 = 你最容易被打脸的地方** → 尽量别碰（路线β风险，压错腰斩）。
- *锚点：FAU/MPO跟光引擎/光纤总数挂钩=跟算力规模挂钩，CPO/可插拔/NPU三路线都要用→收税口；连博通/台积电/COHR都两边下注，散户凭什么赌单一路线(V1)。*

### 1.4 找卡脖子：拓扑位置 ∩ 网格属性
- **公式**：卡脖子 = 拓扑上「价值高 + 可替代性低」 ∩ 网格上「国产化低 + 扩产慢 + 议价强」。
- **动作**：沿链往上每层问"这一层谁最难做、最难替代？"

### 1.5 找"下一个"卡脖子（前瞻，最值钱）★ —— 三句话法
1. 在产业趋势/技术路径上，它**是不是下一个卡点**？
2. 这个卡点**我们有没有真供给能力**（不是吹"能做"，是真能批量、高良率、稳定做）？
3. 这个突破**最终谁来买单**（终端是谁、买不买得起、什么时点）？
- 卡脖子会随技术迭代**迁移**；触发器＝技术路线切换 / 政策制裁 / 下游放量。
- *锚点：EML光源缺→下一个是SOI衬底(硅光路径)→再下一个VCSEL/深化镓；"不是位置低我们才看它，是它能不能回答这三句话"(V25)。*

## 二、横向方法论：网格内比环节、排景气、定范式

### 2.1 第一性：β/α 二分 ★
- **任何组合的第一性问题** = 确定性从哪来 = 这是 **β** 还是 **α**。
- **β**＝全行业供需两旺；**必须横跨"海外算力+国产算力"双循环才是真β**（别被"纯国产/根红苗正"带偏）。β适合"买好待着别动、堆仓位、不绣花"，是买方每年超额的主要来源。
- **α**＝谈不上供需两旺，但有卡点/独点可定价，做弹性。
- **超额怎么来**：① 找下一个β/α的"**转点**"在哪 ② β能否**扩散**（找第二、第三个β，借隔壁行业的β）。
- *锚点：光模块"哪哪都缺、需求没问题供给跟不上"=没β只能涨α；PCB"供给能跟上+海外国产双拉动+价格可验证"=真β可堆仓；β要借半导体β→封装基板载板(V7)。*

### 2.2 统一打分维度（让环节横向可比）
- 维度：国产化率 / 集中度CR3 / 议价权(毛利率水平与波动) / 价值量占比(BOM) / 扩产周期。同维度打分→格子可横向比。
- **"又甜又厚"标准**：甜＝有需求拉动；厚＝供给稀缺有壁垒、能顺价、能撑估值弹性。光甜不厚（往一锅汤里撒把糖）估值提不动，要往上游推到"又甜又厚"的环节。
- *锚点：PCB往上游推到CCL/铜箔/T-glass电子布才"厚"；"炒Q布不如T布拿着别动"(V7)。*

### 2.3 双链交叉验证（网状链的确认方式）
- **规则**：A点要**同时**被 (A→B→C) 和 (A→甲→乙) **两条链验证**才算确认，再向外推九宫格。链状只验一条，网状必须双链。

### 2.4 景气% vs 舆情%（先定性比例）★
- **先给比例**（如"PCB景气3-4成、舆情6-7成"），再决定参与方式。
- **景气三拍**：26订单 + 27景气延伸 + 28宏大叙事。凑齐"上游2+下游2＝四个网格脸"就能炒一波。
- **景气分层（谁是Tier几）**：光存=Tier1 / 光纤=Tier2 / PCB=Tier3。排序决定买方先捡谁。
- **供需供振 vs 单独供给**：单独缺货不够，要"**需求能顺价传导**"才是可持续景气（电子布要能顺价越过26年才敢给估值）。
- **舆情的来源是行为学**：公募新规改基准→没配"光/存/PCB"的买方"脱毛"跑输→被迫追β→卖方/KOL配合编小作文("电子布紧缺到28年")。**故事一看就懂、四个网格脸刚凑齐时，往往已是舆情主导的高位。**
- *锚点：V50 整条就是这套；"我第一性逻辑是选最强的、最猛的、空间最大的，是跑相对收益要排序"。*

### 2.5 估值范式三分层（同一品种不同位置用不同模式）
- **景气估值**（数据驱动，认知壁垒高、品种少、传播差，底子实）
- **主题估值**（叙事驱动，易传播易蛊惑、数据弱）
- **衍生品/期权期货**（高位高估值品种）：把估值锚建在27年 → 做"逻辑体操"把P往下压（提前把高毛利利润拍进来，60×→50×→40×）→ **向下爆炸**（找不到新边际时从"衍生品"降格回"股票"按PE重定价，当期业绩还涨股价却跌）。**追高=追衍生品高点，最后要注销。**
- *⚠️ 量化"复合收割"：在景气↔主题之间来回切，让你筹码和钱都丢。先判当前品种被哪种模式、哪一层主导。*

### 2.6 产融分层映射法（海外内核 → 本土接力）★
- **美股叙事三层 → A股影子三层**：
  | 层 | 美股 | A股影子 | 定位/怎么用 |
  |---|---|---|---|
  | ①结构性景气(26-27没毛病) | LITE/COHR | 旭创/新易盛/源杰(一中元) | **抱团层**，看是否**放量杀跌**(放量=结构性景气跟不上=微观利空反转，常规高波不敏感) |
  | ②总量性景气(谁提capex) | 博通/Marvell(ASIC) | 没订单验证的谷歌链 | **交易性价值**，正股波动放大器，T0打T1、波动率套利，"怼一炮就跑" |
  | ③情绪/舆情 | 甲骨文 | 应用端/端侧 | **观察层**(不交易它)，看情绪冰点，贴水远期期货，"何时不跟甲骨文同跌=做空AI力量拐点衰竭"→回头交易前两层 |
- **用美股做锚**区分：哪些是A股特殊高波，哪些是全球级别高波。别站社交媒体角度(产业级讨论)，要站机构持仓结构角度。
- **本土化估值范式**：国内炒不了"先进制程稀缺"(脱钩)，就换炒"需求 + 中国特色比较优势"(信创/查表场景，差两代也能用)。**先解决"估值范式本土化"，再谈实质。**

### 2.7 大小循环模型（资本开支类品种专用）
- **海外大循环**(memory存储 + logic先进制程) → 映射 **国内小循环**(两长存储扩产 + 中芯先进制程)。
- 两种估值模式：**跟随模式**(蹭，弹性低，情绪化扩张时及时落袋) vs **主导模式**(自主上涨猛干)。**破局点 = 中芯先进制程确定性大扩产**(大芯片良率突破→配HBM→两长切扩HBM→复刻海外双循环共振)。
- 口诀：**静若处子，动若脱兔**(跟随期攒波段，确认正循环果断猛干)。

## 三、边际变化方法论：动态更新

### 3.1 仿真，不预测；超额来自"应对" ★
- 一阶仿真大家结果都差不多(consensus)；**alpha在二阶突变**(地缘/技术路线被证伪/监管转向)发生时——你能否评估冲击大小、决定改不改框架、改哪部分、仓位怎么调。**超额收益不来源于预测，来源于应对。**

### 3.2 拆小作文 / 信源处理 五步法 ★（你特别要的一块）
> 收到任何传闻/小作文/专家纪要，**不要条件反射地恐慌或亢奋**，按五步拆：
1. **回第一性原理**：这东西到底怎么做出来的？（高速板=钢筋(玻纤布)+水泥(树脂)+管道(铜箔)+外加剂(填料)）。底层懂了，哪句真哪句假自己判。
2. **分清结构件 vs 功能件、什么等级、什么工种**：玻纤布分E/T/LowDK三个家族、两条供应链、两波客户——"砸T-glass≈重卡换胎你去做空自行车胎"。
3. **算成本方向**：替代它的更便宜还是更贵？**AI高端材料的利润沿"认证壁垒"方向迁移，不沿"谁便宜"**——换组分会延长认证、反而利好唯一过认证的龙头。
4. **判利好/利空真伪**：**把利好当利空是最大的坑**；"砸认证唯一过关的=有人给你制造打折上车的机会"。
5. **用数据拆、不用叙事拆**：找出"**真正值得盯的那一个点**"(如三季度英伟达中备板定方案)，在那之前所有叙事都是脑补；且至今"看不到任何一手官方规格书验证"就别当既成事实。
- **收尾三连问**（听到"X材料被替代"先问）：① 结构件还是功能件？ ② 哪个等级、干什么工种？ ③ 替代它的更便宜还是更贵？ → **答完就超过90%在群里瞎传的人**。
- **低频品种别用高频信息盘**：光纤拓扑极短(就光棒+光纤)、低频变化，天天拿高频信息盘="绣花把脑子绣坏了"；第一性几个点(供给稀缺/供给结构/需求长久期)**不连在一起看，随便来条信息都能打击单点**。
- *锚点：V12(电子布)、V6(康宁/光纤)。*

### 3.3 会串逻辑 → 拆变量（普通投资者和职业买方的分水岭）★
- **宏大叙事只给方向感，不能给交易结论**。"大胆假设不难，小心求证才难。"
- 把一个大逻辑**拆成"可验证/可跟踪/可比较"的变量，再排序**。"先射箭后画靶子"(用大词堆砌焦虑)≠分析。
- 不要把不同商业模式/现金流来源混成一个宏大命题(英伟达≠甲骨文≠Meta，"都穿西装不等于都是中介")。
- *锚点：拆"AI泡沫破裂顺序"=甲骨文融资难以为继先爆/CoreWeave现金流/Meta砍单先看砍内存还是砍GPU(V61)。*

### 3.4 边际信号体系（前瞻 → 中观 → 确认）
```
前瞻(领先,噪声大)        中观(产业链中段)        确认(滞后,确定)
下游capex/大客户新品      材料价/交期/开工率       月度产销/海关
招标中标/政策补贴         库存周转/排产           季度收入订单/渗透率
```
- 给每个信源标**可信度**：一手财报 > 官方统计 > 二手推算 > 自媒体转引。

### 3.5 拐点识别 ★
- **良性投放 vs 恶性投放**（判周期顶的关键，别一看扩产就喊顶）：
  - 良性＝**用户告诉你要投**(需求清晰、能算账、有期回报)；
  - 恶性＝**对手逼你投**(以量保价，门槛低产能大→价格一波动就扩产→全没利润)。
  - 高集中度 + 高利润品种，会优先"**炸油优化产能**"而非扩产(茅台从不扩产，高利润品种产能波动周期被拉长)。
- **供给结构网络变化才动估值排序**：康宁被英伟达锁"只供美国本土"→海外需求转向亨通/长飞→长飞/亨通/康宁估值排序变。
- *锚点：美光扩产是良性(用户HBM指引到27中)，不是周期顶(V74)。*

### 3.6 排序稳定性 = 景气强弱的诊断信号 ★（找"景气最强环节"的核心抓手）
- **景气叙事个股排序** = 景气(中期供需：供不应求 / 供需两旺 / 供大于求) × 叙事(给个股派男一号男二号绣花)。
- **关键洞见**：
  - 排序**稳定有序**(圆中东易天，调内部不动大结构) = 景气强、**有资格走估值扩张**；
  - 排序**像电风扇**(三花→卧龙→长盈轮流上桌、谁拿单谁涨一段) = "需求很飘、供给很大"、**没有持续性**(只是轮流提估值，谁被踹下桌谁杀估值)。
- **大光出题、小光答题**：大光=确定**叙事**(不是确定景气)；小光=期权/波动率交易，"搓完交卷别裱墙上"。
- **预设重排触发条件**：CPO渗透率 / 归光比例 / 物料解除 → 触发头部梯队重排（排序不是固定的，按景气演进动态调）。
- *锚点：机器人排序混乱=没持续性，要"学学人家中一天，结构有序才有资格估值扩张"(V137)；光"易中天→圆中东易天→源中东易天"(V44)。*

### 3.7 界定风险 > 应对风险
- 先界定：风险**级别多大 / 持续多久 / 哪些可逆哪些不可逆**(滞胀里"滞vs胀"一字之差决定铜能不能空)。
- **影响价格的不是事件本身，而是"大家如何看该事件 → 大类资产定价逻辑的变化"**(交易行为分析)。
- 表演性冲击多(干两周就停)，保持"可逆时跟得上"的连续性；买方只有 all-cash(仅系统性风险)或 no-cash 两态，**放弃交易思路=最大的主观**。

### 3.8 可证伪监控
- 每条多头逻辑配一个**证伪条件**：被证伪即减/清，被强化即加。
- *例(光)：铜连接物理极限被突破→"光替铜"逻辑崩；AI infra资本开支台子塌→第一时间跑。*

## 四、把三轴串成工作流（套到任意一条链的 SOP）

```
纵向 ① 建图 → ② 定颗粒度(拆到可买) → ③ 标"路线无关"节点
            → ⑦ 找当前卡脖子 + 下一个卡脖子(三句话)
横向 ④ β/α 二分(是堆仓还是做弹性?)
            → ⑤ 统一维度打分 + 双链验证
            → ⑥ 景气% vs 舆情% 定性(几成几成?)
            → ⑦ 选估值范式(景气/主题/衍生品) + 海外映射
            → ⑩ 排个股序，看排序是"有序"还是"电风扇"  ← 找景气最强环节落点
边际 ⑧ 收到小作文先拆五步/拆变量
            → ⑨ 扩产是良性还是恶性? 供给结构网络变了吗?
            → ⑪ 设证伪条件，边际变化触发回到①重排
```

## 附：可迁移的"检验问句"清单（把所有 ★ 汇总，贴墙上）

**纵向**
- 这个节点的需求，跟**数量**走还是跟**路线**走？（跟数量走才进作战区）
- 它是不是**下一个卡脖子**？我们有没有**真供给能力**？最终**谁来买单**？

**横向**
- 这是 **β 还是 α**？（β堆仓，α做弹性）真β有没有横跨海外+国产双循环？
- 这一格**又甜又厚**吗？（甜=需求，厚=供给稀缺能顺价）
- **景气几成、舆情几成**？四个网格脸凑齐没有（凑齐≈高位）？
- 海外炒的内核是什么？映射到国内是**抱团层/交易层/观察层**哪一层？

**边际**
- 拿到"X 倍"逻辑，先问：**分母是什么**？
- 拿到小作文：**结构件还是功能件？哪个等级？替代物更便宜还是更贵？**
- 这个宏大叙事，能不能**拆成可验证/可跟踪/可比较的变量并排序**？
- 这次扩产是**良性(用户要)还是恶性(对手逼)**？
- 个股排序是**有序(景气强)还是电风扇(没持续性)**？
- 这条多头逻辑的**证伪条件**是什么？
