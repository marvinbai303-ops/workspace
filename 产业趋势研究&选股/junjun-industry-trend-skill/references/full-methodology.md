# 君君产业趋势skill · 完整说明书

> 这是 `junjun-industry-trend-skill`(展示名:**君君产业趋势skill**,触发词:**君君**)这套 skill 的完整逻辑说明——它怎么刻画产业、怎么判断景气度、怎么验证结论。
> 来源:从一位买方博主("君君/军军老师")的 147 条视频、158 万字转写里蒸馏出的"产业拓扑研究方法论",再结合新增 5 篇 AI/存储周期转写中关于价值池重分配、资本开支久期、长协价现实测试的补充,最终按两个判别维度(景气/主题判别 + 景气度打分)固化而成。
> 定位:**不是荐股工具,是"判别 + 打分 + 验证"的认知工具**。它回答的不是"这股能不能买",而是"现在市场为这只股付的钱,买的到底是什么"。

---

## 0. 一页速览:这套 skill 在干一件什么事

输入:**一只个股 + 一堆研究观点(卖方路演/买方小作文/研报)+ 市场量价数据**。
输出:**①现在交易的是景气还是主题(景气X成/舆情Y成)②景气度打分(底子分 vs 位置分)③可证伪的验证清单。**

整套逻辑挂在**一个最致命的区分**上:

> **"它有没有景气" ≠ "现在涨的是不是景气"。**
> 一只股可以有真景气逻辑,但当前股价交易的是远期叙事 + 杠杆。你判别的是**当下的钱在为什么付费**,不是公司基本面好不好。

所有方法,都是为了不把这两件事混为一谈(混了 = 被"复合收割":在景气和主题之间来回切,筹码和钱都丢)。

# 第一部分 · 底层世界观(为什么这么判)

## 1.1 仿真,不预测;超额来自"应对"
- 散户的"预测" = 猜方向 = 条件反射(残缺数据 + 碎片信息 + 无框架 + 被舆情/K线牵引),不可复用。
- 买方的"预测" = 仿真三步:① 结构化基础数据(不是"miss/beat"摘要,是采购量/利润率模型按时间节点切分)② 景气 S 曲线定位(每个细分 S 形状不同→EPS 不同→增速是算出来的)③ 全局景气推演。
- **关键转折:一阶仿真大家结果都差不多(consensus);超额不来自"预测对",来自对"二阶突变"(地缘/技术路线证伪/监管)的"应对"。**

## 1.2 两套估值模式 + 产融分层金字塔("谁在交易"比"值多少"更重要)
市场参与者分四层,对应两套估值:

| 层 | 角色 | 估值模式 |
|---|---|---|
| ① 产业层 | 产业资本/专家,给产业网格喂准确景气数据 | — |
| ② 金融层 | 把数据编成景气估值范式;另一批在数据空白处用叙事"打粉化妆" | **景气估值**(数据驱动) |
| ③ 庄家层 | 卖方改信源 + 买方做图 + KOL 启舆情,把主题变故事 | **主题估值**(叙事驱动) |
| ④ 大众层 | 老灯(民族情怀/国产替代)/中灯(认知快感)/小灯(搞钱)→ 欲望 → 被收割 |

- **景气估值**:数据驱动,认知壁垒高、品种少、传播差,但底子实。
- **主题估值**:叙事驱动,易传播、易蛊惑、数据弱。
- 升级版主题 = **数据PS**:产融资本进场后,篡改的不再是叙事、而是数据本身(污点扣掉/亮点拔亮/控制业绩发布节奏),长得跟正常产融语料一样,连量化都识别成真。判国产替代/自主科技题材时尤其要警惕。

## 1.3 五条灵魂纪律(贯穿全程)
1. "有没有景气" ≠ "现在涨的是不是景气"。
2. **价量永远只进主题分,绝不进景气分**("涨"不是景气的证据,这是唯一防火墙)。
3. 卖方/买方研究观点是双刃剑(既是景气数据、又是主题加工载体),**必须先过信源闸门再用**。
4. 验证不是找一份更牛的研报来支持结论(那是用叙事拆叙事),而是把结论拆成**可证伪硬变量**、用上下游独立链交叉。
5. **用数据拆,不用叙事拆;区分"已发生数据"和"远期测算"。**
6. **先定久期,再谈景气**:同一个产业趋势,26H2/27/28 交易的不是一件事。没有先把"哪一段时间的利润、成本、产能、技术路线"说清楚,就容易把远期牛市当成近端确定性。

# 第二部分 · 怎么刻画一个产业(产业拓扑)

这是 skill 的"地基"——不先把产业刻画清楚,后面的景气判断都是猜。刻画分三个轴。

## 2.1 纵向:沿价值链把图建出来
1. **画拓扑图**:从终端倒推或从上游顺推,画出「上游资源 → 材料/设备/零部件 → 模组 → 系统 → 终端」。**没这张图,所有判断都是猜的。**
2. **科技/先进制造链是网状,不是链状**:软硬协同 + 全球分工 + **头尾相连闭环**(下游用利润反哺上游,如台积电靠苹果/高通让利支撑先进节点)。所以不能"一个公司一个公司看",要画网格。
3. **定颗粒度**:**一个品类 ≠ 一个词**。拆到"能对应一个具体可买的细分品类/公司"为止(不是"光",是"MP磷化铟衬底/SOI/EML/FAU/MPO插芯";不是"半导体",是"9N高纯氮设备/氦气供应链")。颗粒度不够 = 看不见"顶层着火、地下室漏水"的结构性短缺。
4. **给每个节点贴标签:路线无关 vs 路线相关**。问一句:*"这个节点的需求,是跟数量/规模走,还是跟技术路线选择走?"* 跟数量走 = 路线无关"卖铲人"(作战区,毛物理规律);跟路线走 = 最容易被打脸的地方(尽量别碰)。
5. **找卡脖子**:拓扑上"价值高 + 可替代性低" ∩ 网格上"国产化低 + 扩产慢 + 议价强"。
6. **找下一个卡脖子(最值钱的前瞻)——三句话法**:① 它是不是下一个卡点?② 我们有没有真供给能力(真能批量高良率做)?③ 最终谁来买单?

## 2.2 横向:在网格里把环节互相比
- **β/α 二分(第一性)**:β = 供需两旺(须横跨海外+国产双循环才是真β),可堆仓;α = 有卡点可定价,做弹性。
- **统一打分维度**:国产化率 / 集中度CR3 / 议价权(毛利) / 价值量占比 / 扩产周期。同维度打分→格子可横向比。
- **双链交叉验证**(网状链的验证方式):A 点要同时被 (A→B→C) 和 (A→甲→乙) 两条链印证才算数。
- **供给稀缺内核**:景气最强的环节往往在**上游供给稀缺**(原料/卡脖子),不是利润最大的组装。
- **能否顺价**:紧缺要能顺价传导到下游才是可持续景气。
- **BOM 利润池约束**:一个环节即使真紧缺,也不能无限拿走产业链利润。若单一环节在系统 BOM/运营成本中占比过高(如 AI infra 中存储占比冲到 40%附近),下游会通过砍需求、减配、长协压价、路线替代来重新分配价值。此时判断重点从"这个环节赚不赚钱"变成"它拿走的钱会不会把整条链的资本开支打断"。
- **产融分层映射**:海外炒的内核 → A股影子三层(抱团层/交易层/观察层)。

## 2.3 边际变化:动态更新
- **仿真应对**:超额在二阶突变的应对。
- **拆小作文**(信源噪声处理,见第三部分)。
- **拐点识别**:良性投放(用户要你投)vs 恶性投放(对手逼你投,以量保价→全没利润);供给结构网络变化才动估值排序。
- **个股排序有序度**(诊断仪,见 3.2)。
- **97/久期分析**:每条景气都要标注它穿越哪段时间。先问近端卡的是 26H2 业绩、27 年资本开支、还是 28 年技术迭代;再问它是"柜内/核心系统必须保"还是"柜外/外围开支可砍"。能穿越 26-28 的卡点可防守;只靠 28 年叙事但 27 年成本过不去的,先降权。
- **价值再分配**:AI 产业链调整不等于趋势结束,常常是利润从过度拿钱的环节流回能维持资本开支的环节。买方要先找"谁被迫让利",再找"谁因让利而恢复确定性",而不是简单按涨跌判断景气真假。

## 2.4 AI 大链条专用:先看价值池,再排环节
AI infra 的核心问题不是"哪个环节最牛",而是"全链条能不能继续滚动投入"。

1. **一个环节拿太多,会伤害全链条**:GPU 曾经占比高但能被接受,因为它持续提升算力/效率,老产品降级成中端,让下游获得更高生产率;存储若主要靠 DRAM/NAND 大宗价格上涨拿利润,技术迭代贡献不足,更容易触发下游压价和减配。
2. **先分柜内和柜外**:柜外云存储、外部缓冲、非核心开支更容易先被砍;柜内互连、核心算力配套、必须保证 28 年新品落地的部件更有防守性。
3. **先保增效,再谈降本**:如果某环节 BOM 占比很低(如光互联整体成本占比有限),让它降本很难解决全链条成本问题;它的任务可能是提效、保交付、穿越到下一代算力平台。
4. **买方重排顺序**:成本压力出现后,不是全链条一起完蛋,而是按"成本敏感度低/效率提升高/扩产能解决卡点/久期能穿越"重新排序。光源、部分高速互联、先进代工等可能先被保留;成本高、良率不稳、只靠远期叙事的环节先被降权。

## 2.5 存储周期专用:原厂、模组、服务器不是一条利润曲线
存储是判断产业链周期变化的好样本,因为它同时有原厂价格、长协机制、模组库存、下游资本开支四个变量。

1. **原厂看价格和扩产意图**:近端解法不是 28/29 年扩产大饼,而是 27 年价格怎么平。设备订单/ASML 指引若只够 HBM 转产,不够 DRAM/NAND 实质扩产,市场会理解为近端供给压力仍在。
2. **长协价是现实测试**:当争议从"需求好不好"变成"存储拿走太多利润"时,关键验证点是长协价能否把 3Q/4Q 涨价预期压回去。价格真压下来了、股票不再跌,才是"现实追上股价"。
3. **模组厂是放大的 beta**:存储上行前半段赚库存升值,后半段赚加工费;一旦价格二阶导放缓、长协锁价临近,库存增值空间和加工费想象力都会被压缩。不能把单季度库存利润线性外推全年。
4. **服务器/价格中介也是放大器**:当存储价格预期向上,带存储的服务器/模组可能放大利润;当价格预期向下,它们也会放大负 beta。诊断时要分清公司赚的是产业能力、库存、还是价格中介。
5. **技术替代要看有效期**:内存池化、压缩算法、KV cache 管理等方向长期可能有效,但如果从验证、联盟、标准到产品化需要 1-2 年,就不能拿来解决 27 年的近端资本开支缺口。

> **小结:刻画产业 = 纵向建图(链长什么样、卡在哪)× 横向比环节(哪格最强)× 边际盯变化(什么变了)。**

# 第三部分 · 怎么判断景气度(两个维度)

景气度判断 = **两件事分开做**:① 现在交易的是景气还是主题(判别)② 资产本身景气强不强(打分)。

## 3.1 第一维:景气 vs 主题 判别("现在涨的是什么")

### 灵魂指标(最锋利、最难被骗,优先看)
- **时序错位**:股价启动/涨幅是否**远早于、远超过基本面兑现**?(价先动 = 主题)。本质:**景气是"数据→估值",主题是"图→逻辑"**(买方先把图做起来,你才被引来看)。
- **资金性质**:撑当前这波的是**公募景气资金**(持仓稳步抬升),还是**融资盘/游资**(融资余额快速翻倍 + 超高换手 + 龙虎榜游资 + 股东户数骤降式收筹后高位接力)?

### 综合判别表(汇成"景气X成/舆情Y成")
| 类 | 信号 | 量化口径 |
|---|---|---|
| 景气 | 业绩兑现且加速 | 营收/毛利/净利增速 + 加速度 |
| 景气 | ★顺价传导 | 毛利增速 > 营收增速?毛利率方向向上? |
| 景气 | 供给稀缺内核 | 是否卡脖子环节(功能件/壁垒/国产化低/扩产慢) |
| 景气 | 估值周期可分段 | 价量波动能否一一对上基本面事件 |
| 景气 | 久期穿越 | 近端成本/供给冲击下,该环节是否仍被下游必须保留?26H2/27/28 逻辑是否能分段说清? |
| 主题 | ★时序错位 | 涨幅 ≫ 同期业绩兑现幅度?发布时点卡在拉升期? |
| 主题 | ★杠杆/拥挤 | 融资快速翻倍 + 超高换手 + 龙虎榜游资 |
| 主题 | 估值脱锚 | PE/PB 历史高分位;卖方公开"看远期/对标30倍"=按衍生品定价 |
| 主题 | 利润池失衡 | 单环节占比过高但缺少生产率贡献,下游开始砍量/压价/减配;继续按原高价线性外推 |
| 主题 | 舆情/映射层级 | 讨论量 + 情绪词(国产替代/卡脖子/万亿);小盘高换手=交易层 |
| 红旗 | 数据PS/自相矛盾/单一信源/海外空白区先涨 | 计数,≥2 直接定性"疑似主题" |

### 信源处理闸门(怎么处理你拿到的研报/路演/小作文)
研究观点**不能照单全收**(直接信 = 把主题当景气加)。每条先过:
- **拆小作文三问**:① 结构件还是功能件?② 哪个等级、什么工种?③ 替代它的更便宜还是更贵?(更贵+量价齐升=真顺价)
- **信源五问**:① 可验证性(已发生数据 vs 远期叙事)② 信源手数(一手财报 > 卖方路演 > 买方小作文 > 自媒体)③ 先图还是先数据 ④ 数据PS红旗 ⑤ 越性感越可疑(越往"唯一卡位+快速放量+百亿空间+远期兑现"讲,越是主题被加工的信号)。
- **久期五问**:① 这个逻辑交易的是哪个季度/哪一年?② 近端成本缺口谁买单?③ 它是降本、增效、还是单纯涨价?④ 下游会不会因它涨价而砍资本开支?⑤ 远期技术替代能不能赶上当前问题的时间窗口?
- **分流**:过闸(硬、可验证、多手、能交叉)→ 景气分;不过闸(软、远期、单一信源、先图后逻辑、自相矛盾)→ 主题分 + 红旗。
- **研究材料的正确用法(反直觉)**:它最大价值不是"信",而是 ① 提供可被 iFinD/产业数据交叉验证的"已发生数据"线索(订单/吨数/客户/交付期);② 它本身就是"主题正在被加工"的信号。同一只股若有多份材料,"硬且带caveat"的偏景气、"软且结论式"的偏主题,**两者落差本身就是信息**。

### 三把标尺(用来校准判别)
- **光模块** = 纯景气(估值周期能完整分段解释、上游供给稀缺、排序有序、先数据后估值)。
- **算力租赁** = 纯主题(故事梗传播广、卖方把早期景气外延成长期、买方虚造报表、KOL 情绪套利、先图后逻辑)。
- **自主科技股** = 数据PS升级版主题(产融资本+量化联手、数据被PS到连量化都识别成真)。

## 3.2 第二维:景气度打分("资产本身强不强")—— 底子分 vs 位置分,务必分开

### 底子分(评资产本身,0-100)
| 维度 | 看什么 |
|---|---|
| 景气逻辑强度 | 量价齐升/卡脖子/顺价逻辑是否成立(拆小作文三问通过度) |
| **兑现度** ★ | **今年是否真放量(收入/吨数已落地),还是远期画饼?** 最容易被高估的一项 |
| 供给稀缺/卡脖子 | 国产化率/CR/扩产周期/议价权;是不是真独点(注意瓶颈环节) |
| 久期匹配 | 逻辑对应的时间窗是否和当前估值/业绩窗口匹配;是否能穿越近端资本开支缺口 |
| 价值池健康度 | 该环节拿走的利润是否会反噬下游投入;涨价是否伴随效率提升/供给改善 |
| β/α 定性 | 真β(供需两旺可堆仓)还是只能涨α(卡点弹性) |
| 排序有序度 | 同链龙头队形稳(↑)还是电风扇(↓) |

### 位置分(反向扣)
估值历史分位 + 杠杆(融资) + 拥挤度(换手),越高扣越多。

### 两条关键打分规则(实战校准出来的)
1. **底子分高 ≠ 现在该买**。底子分和位置分必须分开报。典型结论:"底子分中上(逻辑强但兑现弱),位置分极差 = 好赛道、坏时点、坏价格"。
2. **判别的钥匙永远是"兑现度",不是估值高低本身**:
   - 兑现度高 + 估值贵 = **可拿**(广钢气体:在手合同爬坡,PE 80+ 仍随后+67%);
   - 兑现度低 + 估值贵 = **坏价格**(唯特偶:T7没真出货,PE 356 靠杠杆撑)。
   **高估值不能一票否决一个在兑现的真景气。**

### 排序有序度算法(找"景气最强环节"最直接的一招)
1. 取该链头部 5-8 只(预先列清单)。
2. 打分用 **60日区间涨幅 + 主力资金净流入**(别用原始日/月涨幅,均值回归噪声大,会把任何链都读成"电风扇")。
3. 算相邻滚动窗口排名稳定度:**Kendall's τ**(或数"龙一龙二龙三是否换人"的 churn)。
4. τ 高(排名稳)= 景气强、有资格估值扩张;τ 低(电风扇)= 没持续性,先筛掉。
5. 排名**缓慢单调迁移**(因供给稀缺把上游拉进前排)= 景气深化(好);**高频来回跳** = 景气透支(坏)。

# 第四部分 · 怎么验证(把判断升级成可证伪假设)

判断做完不算完——**怎么知道判得对?** 这是博主认识论最硬的一关。

## 4.1 "验证"的标准(先定死)
- ❌ 不是:再找一份更牛的研报来支持结论(用叙事拆叙事,越拆越上头)。
- ✅ 是:把结论拆成**可被独立数据交叉验证的硬变量**(吨数、采购量、交付期、收入结构、资金性质),并对每个变量预设**证伪条件**。

## 4.2 最硬的一招 = 双链交叉验证
- **公司端/卖方说的话,必须被上游链和下游链独立印证。**
- 例:公司说"放量" → 必须 ① 上游原料采购量同步放大(**物理产出,账做不了假**)② 下游大客户落地的批量订单 同时印证。
- **优先信"骗不了的物理量"(采购吨数、交付期),而非"嘴上的指引"。**

## 4.3 证伪条件 + 时序窗口
- 为每个命题写明:**"什么出现 = 我错了(结论被推翻)"** 和 "什么出现 = 结论被验证"。
- 设一个时序观察窗口(通常下 1-2 个季度财报)。
- 对 AI/半导体大链条,必须额外设"现实测试":长协价、资本开支指引、设备订单、客户减配/砍单、技术路线量产时间表。只有现实测试落地后股价不再继续反应,才算利空被吸收。
- 标注每个验证变量:**iFinD 能查 🟢 / 需产业调研·纪要·舆情 🟡**。

## 4.4 数据源映射(每类变量从哪拿)
| 目的 | 指标 | 来源 |
|---|---|---|
| 兑现度 | 营收/毛利/净利增速、毛利增速vs营收增速、分产品收入 | iFinD `get_stock_financials`/`get_stock_summary` 🟢 |
| 时序错位 | 区间涨跌幅 vs 业绩兑现 | iFinD `get_stock_performance` 🟢 |
| 杠杆/拥挤 | 融资余额斜率、换手率、龙虎榜 | iFinD `get_stock_performance` 🟢 |
| 资金性质 | 机构持股、持股基金数、股东户数 | iFinD `get_stock_shareholders` 🟢 |
| 位置 | PE/PB/PS 及历史分位 | iFinD `get_stock_financials`/`get_stock_summary` 🟢 |
| 产能兑现 | 在建工程、固定资产趋势 | iFinD `get_stock_financials` 🟢 |
| 资本开支久期 | 下游 capex 指引、订单节奏、设备公司指引、在建工程 | 财报/纪要/iFinD/公司公告 🟡 |

# 第五部分 · 完整工作流(skill 实际怎么跑)

```
Step 0 收集取数:锁定个股+环节;收齐研究观点(标出处);iFinD 拉硬数据
Step 1 信源闸门:每条观点过五问+拆小作文三问 → 分流 景气分/主题分/红旗
Step 2 久期/价值池定位:标注26H2/27/28逻辑、BOM占比、谁让利、谁恢复确定性
Step 3 景气vs主题判别:综合判别表 + 灵魂指标(时序错位/资金性质)→ 景气X成/舆情Y成
Step 4 景气度打分:底子分(逻辑/兑现度/卡脖子/久期/价值池/βα/排序)vs 位置分(估值/杠杆/拥挤),分开
Step 5 双链验证+证伪:拆可证伪硬变量,公司端话要上下游印证,设"什么出现=我错"+时序窗口
Step 6 输出诊断报告(固定模板)
```

输出模板固定为:**0.一句话结论 / 1.信源处理 / 2.久期与价值池 / 3.景气vs主题判别 / 4.景气度打分 / 5.怎么验证 / 6.跟踪建议**。

# 第六部分 · 两个实战印证(一反一正,证明它在"判别"而非贴标签)

| | 唯特偶(301319) | 广钢气体(688548) |
|---|---|---|
| 产业 | 光模块 T7 超细锡膏(功能件耗材) | 电子大宗气体(照付不议现金牛) |
| 景气逻辑 | 真(量价齐升 T5→T7) | 真(9N制氮+氦气卡脖子) |
| **兑现度** | **弱**(T7 没真出货、增长靠半导体) | **强**(在手合同爬坡、2026Q1净利+63%) |
| **资金性质** | **杠杆游资**(融资3周翻倍、公募0家、年换手643%) | **公募景气**(基金261家、机构45.7%) |
| 估值 | PE 356(高) | PE 80+(高) |
| **skill 判别** | **主题6.5成 → 好赛道、坏时点、坏价格** | **景气7成 → 景气主导、可拿** |
| 实际后续 | 高位主题+杠杆,风险 | KEYCALL后 **+66.9%**,业绩兑现 |

**两个都"景气逻辑真 + 估值贵",但 skill 给了相反结论——靠的就是判别钥匙:兑现度 + 资金性质。**
- 唯特偶:逻辑真但**没兑现 + 杠杆游资** → 现在涨的是主题。
- 广钢:逻辑真且**在兑现 + 公募景气** → 现在涨的是景气。
- 这证明 skill 不会"见涨/见贵/见卖方看多就喊高位",而是真的在判别"当下的钱在为什么付费"。

# 第七部分 · 边界、局限与正确用法(诚实部分)

1. **它是判别/打分/验证的认知工具,不是荐股**;所有点位/个股结论会过期,方法可迁移。
2. **博主的真护城河是私有数据**(产业拓扑库 + 一手调研/纪要 + 专家网络),散户拿不到一手订单/采购/交付期 → skill 这部分只能用代理指标(毛利率/在建工程/进口依赖度)近似,或靠你喂材料。**你机构端能建"产业拓扑库 + 历史复盘样本",这正是该投入的护城河。**
3. **价量永远只进主题分**——这是防止把"涨"误读成"景气"、避免自我复合收割的唯一防火墙,任何时候不能破。
4. **身份校准**:这套源于"相对收益、不能降仓"的机构身份(讲管理波动、不轻易清仓);**个人账户可空仓、做绝对收益**,遇说不清的系统性风险清仓可能就是最优,别硬学"不清仓"。
5. **触发**:对话里带"**君君**"(或 军军/君总)即触发本 skill;带"**白毛**"走 serenity-skill(供应链卡点猎手),两者互斥不抢。
