# CXO修复节奏、订单到EPS的堵点与两年以上持续性

研究日期：2026-09-06。已披露数据以2026H1、2026Q2为主。本轮扩大至海外CRO、全球CDMO、生物工艺供应商及药企客户；不用两只持仓代表行业。不使用聚源。

## 判断

CXO有真实的行业需求修复，已经超过单个中国龙头抢份额能够解释的范围。当前更准确的描述是：商业化生产外包的结构增长，叠加临床外包的周期修复；早研恢复相对滞后，利润率恢复也不普遍。

我倾向于核心商业化CDMO具备跨2026—2028的增长基础，而非仅有一次性大单或补库存带来的偶发景气。但证据尚不足以支持“全部CXO连续两年以上EPS高增长”。行业需求持续、供应商收入持续、股东EPS持续是三个不同判断。

君君框架下的定性评价：
- 需求真实性：较强，客户研发投入、海外CRO净订单、CDMO收入、工艺耗材消费出现交叉验证。
- 量价关系：量的证据强于价格。没有足够证据确认全行业普遍提价或供不应求。
- 利润兑现：明显分化。CDMO中已有量利同升，部分临床与早研仍处成本吸收和定价修复阶段。
- 稀缺性与利润分配：更偏向复杂工艺、可靠放大、质量体系、商业交付及跨区域供应能力；通用人力或通用产能不能自动分享同样的利润率。
- 久期：成熟商业化项目的重复采购与后期项目接续，强于单看融资和BD金额。大分子、ADC、多肽等也需区分成熟交付项目与早期概念。
- 位置：本篇没有重做全行业估值与拥挤度测算，不给数值位置分，不把景气判断等同交易买点。

## 2. 修复节奏：存在两条传导路径

路径A：已有上市药销售放量 → 重复生产采购 → 排产、交付、产能利用率提高 → 利润增长。
路径B：融资/药企研发预算增加 → 真正启动项目、形成净订单 → 临床执行或工艺开发 → 收入与利润。

路径A的项目已越过部分研发不确定性，可以先于本轮新融资驱动的早研项目兑现。因此不能机械使用“早研CRO一定先复苏，CDMO最后复苏”的顺序。

截至本次观察：
- 商业化及复杂工艺CDMO：部分龙头已处收入、利润同步兑现阶段。
- 临床CRO：接单修复的横向证据较广，但服务收入、利润率和EPS兑现高度分化。
- 早研/安评：订单改善领先，有机收入与利润率仍需要进一步验证。
- 上游耗材：重复性采购修复领先于设备；可辅助观察客户真实生产活动。

我的基准推演，而非公司统一指引：2026H2主要观察新订单扩散、执行速度和利润率；2027有条件出现更广泛盈利修复；2028能否延续取决于新订单补充与商业化项目接续。不能给所有CXO设定统一“订单后滞后两个季度就修复EPS”的规律。

IQVIA期末在手订单342亿美元，管理层预计未来12个月转收入92亿美元，约为总在手订单的26.9%。这只是该公司对存量订单的前瞻估计，不是行业平均周期，也不能反推每份合同需3.7年完成。[IQVIA公告](https://ir.iqvia.com/press-releases/press-release-details/2026/IQVIA-Reports-Second-Quarter-2026-Results/default.aspx)

Lonza也明确2026H1受交付时点和低基数支持，H2受计划内业务节奏和更高比较基数影响。即使长需求成立，季度增速也可能先快后慢。[Lonza半年报公告](https://www.lonza.com/news/2026-07-22-06-30)

## 3. 订单到EPS的主要堵点

1. 钱到账后未形成可执行外包预算。融资可能补运营和偿债；BD总额含未实现里程碑；收购方可能调整项目、供应商和执行地区。核心观察首付款、项目启动和净新订单，而不是大额交易标题。

2. 订单名义金额高于自身服务收入的经济价值。需剔除取消，区分框架协议、潜在里程碑、实际服务订单和代付费用。ICON总订单收入比1.51，而直接服务费口径1.2，是典型实证。其Q2调整后EPS按公告数据计算仍同比下降约27.3%，不是订单公告出错，而是不同经营环节和费用的错位。[ICON公告](https://www.iconplc.com/news-events/press-releases/icon-reports-second-quarter-2026-results-0)

3. 项目执行和收入确认延后。临床启动、中心开设、患者入组、方案变更、生产验证、批次交付均可能推后，人员或固定成本却已投入。Danaher的项目时点影响收入，是上下游共同存在的例子。不能拿年底刚签订单解释上半年收入。

4. 有量不一定有更高毛利率。竞争报价、旧低价合同、人员利用率、爬坡成本和业务组合变化都可能吞掉增量。康龙H1 CDMO收入+32.78%、毛利率提升2.57个百分点；临床服务收入+13.75%，毛利率反而下降2.55个百分点。同一平台内部就存在不同修复节奏。[康龙半年报披露原文镜像](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12512750&stockid=300759)

5. 高增长新业务暂时稀释综合毛利率。凯莱英H1新兴业务收入+72.49%、毛利率32.50%；小分子收入-5.44%、毛利率47.83%。新业务占比上升时，即使两个业务各自效率改善，综合毛利率仍可能承压。其H1报表归母净利-15.71%，公司剔除相应调整后的净利+12.90%，汇率是重要差异来源。经调整利润不能替代股东最终报表利润。[凯莱英半年报，第10、14页](https://static.cninfo.com.cn/finalpage/2026-08-25/1225496302.PDF)

6. 毛利到每股收益仍有费用与股本层。汇兑、利息、税率、投资估值、并购摊销以及新增股份都影响EPS。扣非归母净利也不是完全纯粹的经营利润；按公司自行调整的利润更需阅读调节表，不能只取最好看的口径。

7. 回款和扩产影响现金质量。收入确认可能快于收款；库存、合同资产与应收占用资金。扩产资本开支先影响现金流，之后经折旧、人员和利用率影响利润，不是当期全额费用。康龙H1经营净现金流同比-22.98%，但单项下降不足以认定坏账或虚假订单，需看收款、付款与营运资金明细。

8. 全球需求未必完整流向中国供应商。自建产能、双供应商、客户区域化采购以及政策可能改变份额，并增加海外基地成本。礼来同时增加自建制造投入，不能把终端药品放量都映射成某家CXO订单。[礼来公告](https://investor.lilly.com/news-releases/news-release-details/lilly-reports-second-quarter-2026-financial-results-raises-full)

## 5. 两年以上景气的证据与反证

支持长周期的证据：
- 全球药品真实销售驱动重复生产。礼来Q2收入+48%，主要由Mounjaro、Zepbound销量拉动；这证明相关终端需求，不能据此认定具体中国供应商客户身份。[礼来Q2](https://investor.lilly.com/news-releases/news-release-details/lilly-reports-second-quarter-2026-financial-results-raises-full)
- 商业化合作已超出单次订单。Lonza在7月扩大既有美国药企多年合作，新增两个商业化生物药项目，另有两个选择权。选择权和潜在累计合同金额不能作为确定收入；但已签的多年多项目合作比单纯融资金额更支持久期。[Lonza合作公告](https://www.lonza.com/news/2026-07-01-07-00)
- 后期项目已有接续储备。药明生物截至6月底有78个III期项目、28个商业化项目；三年内订单55亿美元、同比约+30%。总订单251亿美元中含124亿美元潜在里程碑，不宜把全部总额看成确定生产订单。[药明生物半年业绩](https://www.wuxibiologics.com/press-release/wuxi-biologics-reports-strong-profitable-growth-in-h1-2026/)

长需求仍可能对应低利润：
- 竞争对手和药企内部产能同步扩张，技术进步降低单位生产用量或价格，量增不一定产生定价权。
- 需求集中少数药物、客户或治疗领域时，竞争、价格变化和路线变化影响供应商份额。多肽、口服小分子、抗体等服务能力不完全通用。
- 项目多年执行意味着收入分期，并不意味着每年都增长；新增订单需要持续补充被执行和被取消的存量。
- 低基数、补库存、一次性里程碑以及交付集中，能把某半年增速抬高，不能外推两年。
- 全球外包贝塔与中国供应商份额风险必须分开看。药明康德1260H事项8月7日获得初步禁令限制执行，属于诉讼阶段措施，不等于最终判决或所有潜在采购限制消失，也不能直接断言已经系统性断单。[法院意见，Justia收录](https://law.justia.com/cases/federal/district-courts/district-of-columbia/dcdce/1%3A2026cv02069/293402/25/)

据此，我对长周期证据强弱排序为：
1. 已有商业化交付、后期项目梯队和全球质量能力的CDMO：最强。
2. 全球临床CRO：中等；订单共性已经改善，但利润、执行和客户集中差异仍大。
3. 早研及通用产能：仍按周期修复评估，暂不给无条件两年以上高景气假设。

## 6. 不跟单条管线也能做的季度验证

这是研究规则建议，不是已获行业共识的机械阈值。

| 简化看板 | 观察方法 | 什么情况会下调判断 |
|---|---|---|
| 海外临床CRO净订单 | IQVIA、Medpace、ICON至少跨两家，滚动观察；统一取消与代付费用口径 | 多家公司净订单持续低于收入，且未来12个月可执行订单下降 |
| 早研实际执行 | Charles River安评业务有机收入与利润率是否共同改善 | 接单改善后连续两个报告期收入和利润率仍无改善 |
| 生产需求旁证 | Sartorius重复耗材、Danaher工艺订单与实际收入，并与CDMO交付对应 | 上游订单强但交付反复推迟，耗材与CDMO收入也转弱 |
| 利润兑现范围 | 比较龙头有机收入、毛利率、经营利润和EPS调节项 | 盈利增长越来越依赖费用调整、投资收益或并购 |
| 久期与现金质量 | 近12个月/三年内可执行订单、商业化接续、经营回款与应收周转 | 长订单标题增加，可执行部分、回款和滚动接单却恶化 |

不追管线可以抓到行业贝塔；难以仅凭这些汇总数据判断某个临床项目成功率及小公司的分子级超额收益。对只持有几周的交易，还需单独处理估值、预期和价格，不能把两年产业判断自动改造成持仓承诺。
