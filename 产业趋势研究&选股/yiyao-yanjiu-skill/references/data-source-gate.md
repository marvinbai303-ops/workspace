# 数据与信源闸门

## 1. 优先级

按以下顺序取证：

1. 监管机构、交易所、审评和临床登记原始数据；
2. 公司公告、定期报告、招股书、试验方案和正式演示材料；
3. 可追溯到原始记录的专业数据库；
4. 有明确来源和口径的卖方报告；
5. 纪要、专家访谈、买方材料；
6. 媒体、自媒体和市场传言。

低层级来源可以发现因子，不能替代关键数字的原始来源。所有当前数字记录“数值、单位、口径、截止日、来源链接或公告名称”。

## 2. 数据可用性规则

- 官方临床登记、监管受理和公司财务数据：原始准确性通常高，但经济解释仍需去重和口径清洗。
- 融资与BD数据库：时效性较好，但可能漏单、重复或把里程碑计入总额。
- 在手订单、新签订单和项目数：公司内历史可用，跨公司可比性通常低。
- 终端销售、净价、真实产能利用率、客户项目映射：公开数据往往不足，必须标记限制。
- 市场规模与外包率预测：只用于情景边界，不进入核心评分。

## 3. 缺失和冲突处理

- 缺失值记为 NA，不填 0，也不填中性 50。
- 两个来源冲突时，优先原始口径，并列出差异原因；不能消除则降低可信分。
- 同一指标口径发生变化时，不直接计算同比；先重述或只做同口径区间。
- 未披露的新签订单、利用率、复购率等，不得用收入增长倒推为已知事实。
- 所有估计值必须与已披露值分栏呈现。

## 4. 时间要求

- 市场价格、成交、融资和事件：使用研究日可得的最近数据。
- 财务与订单：注明最新报告期，不能把半年或年度数据描述为实时。
- 临床与监管：注明登记或公告更新时间，并检查试验状态是否已更新。
- 机构持仓：注明季度滞后；不得当作当日持仓。
