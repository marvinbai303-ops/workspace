# 个股三分机制

三项分数分别回答不同问题：

- **机会分**：基本面和未来兑现质量是否值得继续研究；
- **数据可信分**：当前结论有多少可核验数据支撑；
- **位置风险分**：价格、资金和拥挤是否已透支。分数越高，位置风险越大。

不得把三项直接相加或相减为一个总分。高机会、高位置风险意味着资产逻辑可能成立，但赔率和时点差；不等于机会被否定。

## 1. 机会分

每个维度 0–100，再按权重汇总。只使用基本面、项目、订单、财务和可验证催化，不使用股价、换手或舆情。

### 创新药公司

| 维度 | 权重 |
| --- | ---: |
| 临床/注册证据与资产质量 | 30% |
| 差异化、竞争格局与技术平台 | 20% |
| 催化剂和阶段迁移可见度 | 15% |
| 商业化、支付与BD质量 | 15% |
| 资金跑道、CMC和管理层执行 | 10% |
| 政策、生产与其他基本面风险回报 | 10% |

### CXO 通用框架

| 维度 | 权重 |
| --- | ---: |
| 外部需求与景气传导位置 | 20% |
| 订单质量与可见度 | 25% |
| 项目阶段、客户和技术路线结构 | 20% |
| 交付、产能利用与经营杠杆 | 20% |
| 现金流与财务质量 | 15% |

分型调整：

- 临床 CRO：外部需求15%、订单25%、项目执行与人员效率30%、经营杠杆15%、财务15%。
- 临床前 CRO：外部需求15%、订单25%、项目/技术20%、设施利用与经营杠杆25%、财务15%。
- CDMO：外部需求15%、订单25%、项目阶段与技术20%、产能/交付25%、财务15%。
- CRDMO：外部需求15%、订单20%、项目迁移/交叉销售30%、交付20%、财务15%。

公司同时包含创新药和 CXO 时分别评分。只有分部收入、利润或价值暴露可合理估计时才合成，否则并列报告。

## 2. 数据可信分

先给每个机会因子计算可信度：

```text
因子可信度 = 来源质量×35% + 交叉验证×25% + 新鲜度×20% + 口径完整/可比×20%
覆盖率 = 已取得有效数据的机会分权重 / 100
总数据可信分 = 已有因子的加权平均可信度 × 覆盖率
```

来源质量参考：原始监管/审计披露 90–100；公司正式非审计披露或可追溯数据库 75–90；可追溯卖方数据 55–75；纪要或二手媒体 30–55；传言 0–30。

规则：

- 覆盖率低于70%：机会分标记“信息不完整”，不得进入跨公司排名。
- 总可信分低于60：结论只能写为暂定判断，并列出最关键缺口。
- 单一公司口径的订单或利用率不能因来源为公告就自动获得高“可比性”分。
- 缺失因子保持 NA，不能按50分补齐后继续排名。

## 3. 位置风险分

### 行业温度

沿用创新药/CXO温度计口径：

| 指标 | 权重 |
| --- | ---: |
| 10日换手均值历史分位 | 15% |
| 10日成交额占全市场比重的历史分位 | 15% |
| 成分股创新高广度 | 20% |
| 相对120日均线乖离的历史分位 | 15% |
| 融资杠杆/融资交易活跃度 | 15% |
| 公募基金仓位历史分位 | 10% |
| 舆情讨论热度 | 10% |

行业温度只描述行业交易位置，不证明行业景气。

### 个股位置风险

```text
个股位置风险 = 行业温度×30% + 个股热度×70%
```

个股热度内部权重：10日换手分位20%、成交拥挤15%、120日均线乖离15%、融资杠杆15%、机构持仓/筹码集中10%、估值历史分位15%、舆情热度10%。历史分位尽量使用至少三年数据；上市不足三年时明确缩短窗口。

若某指标不可得，记为 NA 并同步降低位置风险的数据可信度，不得静默重分配权重。行业温度不可得时，可以报告个股热度，但不得伪装成完整位置风险分。

风险区间：0–59为低温/较低风险，60–74为升温/中等风险，75–84为高温/高风险，85–100为极热/极高风险。

## 4. 机会—位置矩阵

| 情形 | 研究含义 |
| --- | --- |
| 高机会、低位置风险 | 基本面与赔率同时值得优先研究 |
| 高机会、高位置风险 | 逻辑可能成立，但价格领先，需要等待兑现或降温验证 |
| 低机会、高位置风险 | 更接近主题或流动性交易，优先检查叙事与资金撤退风险 |
| 低机会、低位置风险 | 可能是冷门、价值陷阱或尚未出现催化，不自动等于便宜 |
