# 输出模板

## 一句话结论

说明属于创新药、CXO、两者兼有或均不适用；给出最重要的机会与风险判断。

## 框架适用性

- 创新药框架：适用 / 部分适用 / 不适用；理由。
- CXO框架：适用 / 部分适用 / 不适用；若适用，列出业务分型。
- 研究时点和数据截止日。

## 景气传导位置

仅在 CXO 适用时输出：

- 领先节点：S0–S6及证据；
- 已确认节点：S0–S6及证据；
- 传导断点或背离；
- 当前方向与下一观察窗口。

## 三分卡

| 分数 | 结果 | 解释 |
| --- | ---: | --- |
| 机会分 | 0–100或NA | 列出各维度贡献，不能用价量加分 |
| 数据可信分 | 0–100 | 同时写覆盖率、关键缺口和来源层级 |
| 位置风险分 | 0–100或NA | 行业温度、个股热度及缺失项 |

## 关键证据与反证

分为已发生硬数据、公司指引、外部推演和市场叙事。列出至少一个可能推翻当前判断的条件。

## 后续验证

列出变量、数据源、预计更新时间和触发阈值。若数据不足，直接说明暂时不能排名或不能下结论。
