# 样板间组合日报系统说明书

## 一、系统概述

本系统每个交易日先用 iFinD 查询底层基金最新复权单位净值，再按 Excel 跟踪模板中的组合公式口径重算 6 个样板间组合的预估净值、日收益和回撤，并写回 Excel 缓存，最后生成标准化图片报表并推送至 Slack。

***

## 二、更新时间

| **阶段**   | **时间**        | **说明**                       |
| -------- | ------------- | ---------------------------- |
| 自动触发     | 北京时间 21:30    | 周一至周五每日触发                    |
| iFinD 检查  | 21:30 → 23:00 | 每 30 分钟检测一次，等待 24 只底层基金最新复权单位净值齐全 |
| 超时截止     | 北京时间 23:00    | 超时仍未取齐或校验失败则不出正式报表，只写失败日志和推送失败摘要 |
| Slack 提醒 | 报表生成后         | 推送"已更新"提示至 Slack             |

> **注意**：节假日及非交易日（周六/日）不自动触发。

***

## 三、计算口径

### 3.1 今日涨跌幅（日度）

* 来源：iFinD 底层基金最新复权单位净值 + Excel 模板公式口径
* 自动任务按 `分期持仓明细` 当前生效持仓、累计因子、`实盘持仓配置` 年化费率和起始日重算组合净值
* 日收益 = 当日重算组合净值 / 上一有效组合净值 - 1
* 重算结果写回 Excel `实盘净值数据(iFinD公式)` 与 `实盘组合净值` 的公式缓存，再由报表读取

### 3.2 管理费扣除

* 管理费扣除逻辑沿用 Excel 模板公式：按组合年化费率折算到每日
* 自动任务用模板同一参数重算已扣费后的组合净值和日收益
* 组合年化费率仅用于报表展示，来自 Excel `实盘持仓配置` 表

### 3.3 累计涨跌幅

* 累计涨跌幅 = Excel 最新组合净值 − 1
* 自动任务不维护独立基准净值，避免与 Excel 权重漂移口径不一致

### 3.4 模拟净值

* 直接取写回后的 Excel `实盘组合净值` 表最新有效日期行的组合 `净值`

### 3.5 货币基金处理

* 货币基金使用 iFinD 返回的复权单位净值；异常检测中不按普通权益基金的日波动规则拦截
* 列表中货币基金排在最末

## 五、数据校验机制

每次计算完成后，系统自动执行以下5项校验：

| **校验项**     | **规则**         | **异常条件**       |
| ----------- | -------------- | -------------- |
| **权重求和**    | 各基金权重合计应为 100% | 偏差 > 0.1% 报错   |
| **底层净值齐全** | 24 只基金均需解析到最新复权单位净值 | 任一缺失则等待下一轮 |
| **疑似未刷新** | 非货币基金最新净值与上一交易日完全相同数量 | 达到阈值则阻塞，避免误用旧值 |
| **异常涨跌幅检测** | 单只基金日涨跌幅异常 | 超过 ±10% 记 WARN，超过 ±20% 记 FAILED |
| **组合极端波动兜底** | 组合日涨跌幅异常 | 超过 ±10% 记 FAILED；不因 ±5% 波动报警 |

### 报警触发条件

Slack 提醒内包含如下状态字样时表示有问题需人工核查：

* `❌ N项失败`：数据校验失败，数值逻辑存在问题，**不建议对外发送**
* `⚠️ N项警告`：存在异常涨跌幅等可疑数据，建议人工确认
* `(T-1)` 标注：图中某基金名称旁出现此标注，表示该基金当日净值未及时更新，使用的是前一日数据，**该组合当日涨跌幅偏差较大，请特别留意**

校验全部通过时显示：`✅ N项通过`，并附注"数据完整，所有校验通过，可对外发送。"

## 六、T-1 标注说明

当某只基金在北京时间 23:00 前仍未发布当日净值，或 iFinD MCP 暂时返回空表时：

* 系统不会用旧值硬凑正式报表
* 本轮写入 `reports/run_logs/ifind_recalc_YYYYMMDD.json` 和 `summary_YYYYMMDD.json`
* Slack/Gmail 推送失败摘要，列出缺失基金或疑似 stale 原因
* 下一轮仍会继续尝试，直到 23:00 截止

## 七、注意事项

1. **数据来源**：iFinD 最新复权单位净值，非实时行情，通常于收盘后 19:00–22:00 陆续更新
2. **与系统数据的差异**：组合计算尽量复用 Excel 模板公式口径，但 iFinD 底层净值发布时间和系统确认口径仍可能存在轻微差异，**请以系统数据为最终依据**
3. **节假日**：系统不判断 A 股节假日，如遇节前/后交易日，净值日期可能与触发日期不一致，属正常现象
4. **调仓口径**：组合级净值、今日涨跌按 Excel 模板的调仓生效行、累计因子、基准净值行和年化费率口径计算；不是简单用初始权重乘当日涨跌。
5. **持仓明细展示**：持仓页仅展示持仓权重、今日涨跌和今日贡献；底层基金累计涨跌/累计贡献因调仓日期基准不一致，不在报表中展示。
6. **2026-07-16 调仓模板**：当前任务使用 `样板间投顾组合监控模板-20260716调仓.xlsx`。10-90、10-90基石、30-70 自 2026-07-17 起使用 `分期持仓明细` 的 P3 最新持仓比例；详情页持仓也按该生效日自动切换。

### 8.1 自动任务命令

```bash
python3 run_daily_guarded.py --excel 样板间投顾组合监控模板-20260716调仓.xlsx --outdir reports --email-to me --slack-channel-id C0BHVGDAHN0
```

自动任务创建为 Codex cron 后，每周一至周五北京时间 21:30 运行。守门脚本会从 21:30 开始调用 iFinD 查询底层基金最新复权单位净值；未就绪或校验失败时每 30 分钟重试一次，最晚等到 23:00。

### 8.2 守门与日志机制

* **刷新检查**：24 只基金净值必须齐全；若多只非货币基金最新净值与上一日期完全相同，则判定疑似未完整刷新。
* **异常检测**：单基金日涨跌幅超过 10% 记为警告，超过 20% 记为失败；组合层面不因 5% 波动触发警告，仅当组合日涨跌幅超过 10% 时记为失败兜底。
* **成功防重复**：同一目标日期已有 `SUCCESS` 或 `WARN` 摘要且输出文件齐全时，脚本直接 `SKIPPED`，避免重复生成。
* **日志文件**：每日摘要写入 `reports/run_logs/summary_YYYYMMDD.json`，流水日志追加到 `reports/run_logs/daily_run_log.jsonl`。
